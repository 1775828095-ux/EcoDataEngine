# 自主组合与统一判优交付（2026-10-27）

## 本次完成及边界

新增平台公共 `Autonomous` 模式，页面提交、文件请求和 Python API 共用入口。取消 Robit 实验脚本中四种方法、40 张完整图的手工候选池；改为扫描注册库，依据真实父节点兼容性逐层提出节点、先后连接及多父节点连接。没有人工最大处理步数，仍保留有限计算资源的停止条件。原有 Profile、Composition 和历史 GOLEM 入口保留。

**链路已执行，不代表效果优越或全局最优。** 当前自动数值评价支持单站逐日缺失恢复；空间、多源任务没有在这个新模式中完成自动评价验收。不能把本次交付解释为所有任务的通用自主优化均已完成。

## 平台如何自行判断

1. 硬条件依据插件实际兼容性、任务单位、时间语义、支持域及非负要求判断，不用画像软分指定赢家。
2. 仅从输入可见观测再遮挡，所有候选共用冻结遮挡。按自然年划分时间窗；不足两年时按月，仍不足两个窗口则停止，不虚构准确率。
3. 本轮搜索窗为 2002—2006，确认窗为 2007；每窗三组固定遮挡。真实原始缺失不计入误差。恢复统计状态复用此前 1990—1995 拟合状态。
4. 统一目标为 `J(G)=mean_window(mean_seed(RMSE(G,window,seed)))`，越小越好。经验最优和单算法基线都按同一个 J 选取；同分优先实际算法节点较少的图。MAE、Bias、窗口离散程度同时记录。
5. 确认阶段只比较搜索期冻结的经验最优与搜索期最强单算法。组合必须在每个确认遮挡上不差且平均严格更好，才替换基线；否则保留基线。这是预定稳定性门槛，不是统计显著性或未知年份的性能保证。
6. 每张图经现有 NumericalDAGExecutor 真实执行。未恢复完整的结果只作为中间状态继续扩展，不用“成功恢复的子集”计算误差。最终输出恢复原始可见值，保护原观测。

本轮不用三画像软分、遗传变异或另一套学习排序。采用逐层开放图探索，以先查清可执行空间和判断机制；没有把它包装成变异算法优势。实际天气运行效果、SWAT 径流效果仍未知。

## 搜索空间和停止含义

注册库当前有 95 个注册项，其中 73 项标记 available；其中包含校验器、包装器，并非 95 种独立科学方法。所有 73 项在本轮都有实际兼容性尝试，不因旧实验只用了四种恢复方法而排除其余项。

有声明的参数域逐项展开；本轮缺口阈值来自输入实际缺口长度，未沿用手填 1/3/7。参数域缺失时只能试注册默认值，记录覆盖未知。旧库 91 个注册项缺少完整端口数量或参数域声明，不能据此计算全库合法组合总数。未声明端口数量的插件按逐层资源允许尝试多父节点。

状态按全部搜索遮挡的数值结果去重，保留图及别名；对未声明状态完备性的插件，这只是工程探索策略，不构成全结构空间等价证明。全局认证要求可执行的有限参数域、确定性、状态完备契约和实际空间闭合；域/契约解析错误也禁止认证。

资源上限是 180 秒、3000 次提议、80 次候选真实执行，先到者停。单候选内部还可能调用多次算法，因此另记实际内核调用。第三方内核没有进程级硬超时，预算在内核调用之间检查。预算、确认和部署成本均披露。

## 本次真实结果

采用 Robit 2002—2007 单源逐日降水。此批年份和外部参考已在历史工作中使用，**本次是机制诊断，不是新盲测**。确认窗对本次搜索隔离，但不能恢复历史已经失去的盲性。

| 项目 | 结果 |
|---|---:|
| 连接/参数提议 | 852 |
| 不兼容提议 | 772 |
| 候选真实执行 | 80 |
| 可完整评分候选 | 22 |
| 仅中间状态候选 | 49 |

| 总记录时间 | 21.09 秒 |

本轮真实执行图包含一、两个算法节点；提出了双父节点连接，但这份单站输入下双父节点提议没有形成可执行产物。定向合成测试另外验证了新注册算法自动进入、多父节点组合真实执行；不能用合成测试宣称 Robit 存在组合收益。

最终选中 `g21`：`source → reconstruction.daily_month_mean(max_gap_days=14)`。搜索目标 J=6.666195 mm/day；确认平均 RMSE=6.174676 mm/day。它本身就是单算法基线，**没有发现组合收益**。用旧参考做选择后的探索性回读，232 个缺失点 RMSE=9.727667 mm/day；评价年份与遮挡不同，不能直接与上一轮独立测试汇总 7.747872 作胜负比较。

失败保留：1 次结果质量门拦截；8 次后续日恢复没有足够有效观测，主要来自不适合当前任务的中间状态。未改规则掩盖失败。大量空间、训练或多源插件因当前输入不满足条件而被拒绝，具体原因逐项存于 attempts.jsonl。

首版串行调度运行也保留。发现其参数/注册顺序可能先消耗预算后，改为按复杂度、父节点数及插件公平轮转；没有改误差目标、遮挡、数值算法或质量门。调度修正说明与首版源码另存。两版选出相同的数值结果，未宣称修正带来科学优势。

停止原因为 RESOURCE_BUDGET_EXHAUSTED，认证为 NOT_CERTIFIED_CURRENT_BEST_ONLY。没有算完合法空间，也没有证明真实未知值的全局最优。
