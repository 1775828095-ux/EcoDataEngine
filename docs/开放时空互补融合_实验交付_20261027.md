# 开放时空互补融合：实验与平台交付

## 结论

**这组控制退化实验出现了实际优势。** 自动选图的测试主指标为 1.0373 K，开发期最强固定图为 1.2986 K，平均降低 **20.12%**；四个时段案例赢三个、输一个。不能写成稳定普遍领先，不能写成全局最优。

主指标是“每帧空间RMSE，再对时段案例及三个种子等权平均”，不是把所有像元和重复种子当成独立样本。四个案例合计14×64×4=3584个隐藏值；三个种子重复使用同一真值，不增加独立案例数量。

| 方案 | 测试主指标 / K | 自动选图相对误差降低 |
|---|---:|---:|
| 精细源单独处理，开发选出的最好已发现单源流程 | 2.5884 | 59.92% |
| 粗源单独处理，开发选出的最好已发现单源流程 | 3.5181 | 70.51% |
| 开发期最强已发现固定图 | 1.2986 | 20.12% |
| 随机探索，同为180次候选执行 | 1.9296 | 46.24% |
| 随机探索，按自主探索实际时间配对 | 1.9296 | 46.24% |
| 输入内锚点自验证＋开放图探索 | **1.0373** | — |

最强固定图不是所有可能固定方案的全局最优，而是对开发搜索实际发现的 **247种不同图/参数配方全部跨开发案例重放**后选出的最好方案。自主搜索没有被限制在这247张图内。

## 实验如何开展

复用现有 `data/ncep_xarray/air_temperature.nc`、面积平均降采样、语义时间重采样、空间插值/重网格、滤波及现有细节投影融合内核。

每个案例17个六小时时刻：A源为8×8网格，每48小时一帧，共3张；B源为4×4网格，每6小时一帧，共17张。目标恢复全部时刻的8×8温度。

**这是同一真实NCEP场构造的互补双输入，不是两个独立传感器。** 原生精细网格仍是2.5度，“高空间”仅相对降采样粗场而言。不能据此声称已验证米级遥感融合、真实双传感器融合或SWAT/WRF效果。母数据历史上已经使用，本轮不能宣称是全新外部数据。

开发为两个早期时段/西侧区域，验证为两个中期时段/中部区域，测试为四个后期时段/另一区域。具体索引和哈希已冻结。四个测试时段位于同一个留出区域，不能称为四个独立流域或四个独立地理域。

对新输入，平台公共入口自动隐藏中间一张可见精细锚点，只用首尾精细图及全部粗图生成候选。中间锚点仅由独立评分器计算误差，不进入科学算法及观测算子。选图、参数冻结后，用全部三张原本可见的精细图重新执行，测试只评价锚点之外14张从未提供给平台的精细图。

这是输入内自监督选图：依赖至少三张可见精细锚点，不能声称无任何参考就能知道真实误差。原定36份最终产物与补充时间配对随机对照12份产物，均先保存哈希清单，之后才计算最终测试效果。没有按最终测试结果调整权重或替换种子。

## 平台实际做了什么

新增公共 `PlatformSearch/AutonomousField`；页面、文件请求及Python入口走同一个分发函数。复用95个基础注册项，其中73个标记可用；对缺乏时间批处理的算法自动生成逐帧适配，最终共158项注册（含63项适配器），136项可用。适配器不是新增63种科学算法。

候选生成使用真实父节点接口；新状态继续扩展，允许逐源不同算法、先后处理及多父节点融合。优先扩展与目标坐标/时间更接近的状态、优先尝试跨源连接；这些优先级不读取隐藏真值。没有手写完整流程池，也没有人工最大处理步骤。连续融合参数在算法声明的物理允许域中采样，其余未声明参数域仅试原注册默认值，明确保留覆盖未知。

评分为实际隐藏锚点的空间RMSE；每个候选真实执行。同分优先较少实际算法节点。输出支持域、有限值、单位、非负要求与变量语义须满足任务合同。失败图和仅能作为中间状态的图均保留，不用成功子集给不完整图刷分。

本轮是开放DAG探索与参数采样，**未使用GOLEM或遗传变异**，所以这些结果不能证明变异算法的优势，也不能称为三画像软评分的优势。用户此前允许移除三画像软评分，本轮目标是检验真实选图和数值收益。

最终自主方案均调用实际双源细节融合，典型流程为：精细源时间插值；粗源空间重建；两支在目标网格/时间汇合；现有细节投影内核结合粗场动态与细场结构。不同案例/种子改变空间重建与细节强度，而不是搜索去匹配一条指定标准答案。

## 组合内核的物理含义

现有内核先得到 `z=α·fine_proxy+(1−α)·coarse_proxy`，再作 `z+Aᵀ(AAᵀ)⁻¹(y_coarse−Az)`。A是本次明确声明且与降采样一致的面积平均观测算子。它约束输出回到粗网格后与粗观测一致；不能将温度面积均值一致性称为质量守恒。未知亚网格细节仍由可见精细锚点提供，不能凭空恢复未观测细节。

开发固定图选中粗源普通克里金近似重建、精细源时间插值及细节强度0.437741。自主方案用当前输入隐藏锚点选择算法和强度。0.437741是开发评价产生的值，不是人为加分权重。

## 负结果、稳定性与成本

按案例平均，自主选图相对固定图的误差改善依次为 **0.0971、0.6571、0.4092、−0.1181 K**。第四个案例输给固定图。按四个时段块重采样的描述性95%区间为 **[−0.0105, 0.5331] K**，跨零；样本少，不能声称对固定图具有统计上可靠的普遍优势。

三个种子的全案例平均误差分别为 **0.9235、1.0905、1.0980 K**；第四案例的三个种子约为1.2157、1.5344、1.9867 K。稳定性仍需改善，不能只报告最好的种子。

原定相同候选执行上限不等于相同内核成本：测试中自主探索平均约 **25.05秒、752.3次内核调用**；原随机探索约 **18.90秒、348.3次内核调用**。补充时间配对随机探索约 **26.23秒、629.9次内核调用**，最终主指标1.9296 K。它同样不如自主选图，但不能将相同墙钟配额解释为完全相同CPU或内核成本。

三个进程并发，机器其他负载影响计时；没有据此声称速度最优或相对固定图的计算效率优势。开发固定对照另花64.03秒重放247配方、508次适配器调用；工程诊断与独立审计也没有算成搜索优势。

最终开发6次、验证6次、原定测试24次、补充成本对照12次，共48次运行，真实执行 **9767个候选、29826次内核调用**。逐帧适配器内部原算法调用已计入；出现 **478次候选执行失败**，全部留存。失败主要包括：主辅平均收到不一致的空间语义；重建后非负投影被提议到尚未对齐的粗网格；三次插值收到非有限中间值。它们没有成为最终合格输出，不能把“尝试了一条图”写成“这条图可用”。

预先声明的资源上限是180次候选执行、40000次提议、120秒，先到者停止；补充随机对照提高候选上限以按实际时间配对。它们是资源停止边界，不是合法组合池。图可继续增长且含连续参数，旧库部分参数/状态契约不全，**合法空间未闭合、没有穷举最优参照，也没有全局最优认证**。

## 独立验收与版本

- 23项最终相关回归通过；另有28项较早的兼容/页面回归、13项公共接口与日恢复回归记录。测试数有重叠，不相加冒充独立数量。
- 独立重放36次测试/成本对照的选中图：隐藏锚点评分与日志一致；全部可见锚点部署的产物与保存文件一致；36份原定预测的哈希一致。
- 交付前补强终端语义门，禁止仅单位相同但变量类型、空间支持或时间语义改变的结果取得误差分。冻结源码、单一增量diff与当前哈希分别保存。
- 额外重放全部48次运行的原选中图，严格语义门下仍合法且误差一致。该门仅收紧评分集合，不改变按坐标/节点数生成状态的调度；原最小值仍合法，因此不需重选参数或对同一测试反复调优。没有重跑整个搜索，不能把旧耗时冒充补门后的新计时。
- 批量重网格与原逐帧数值按1e−12容差一致；无外部参考时自动隐藏锚点、没有可用参考时拒绝虚构精度、错误物理支持不能评分，均有定向测试。
- V1—V5开发诊断、失败接入及计时剖析保留；修复输入数量、真实对齐要求、重复排序和批处理后，V6才进行本次完整对照。

主要源码：`src/ecodata/algorithms/autonomous_field.py`、公共`platform_search.py`分发、`spatiotemporal_detail.py`与`composition_decision.py`公共参数提议、旧算法输入数量声明及页面入口。数值算法复用原库，没有重新训练替代排序模型。完整实验、对照、产物、图、参数、成本与版本证据位于 `output/open_complementary_20261027`。

## 能证明到哪一步

本组控制数据上，互补信息融合明显优于两个单源方案；输入内锚点选图比开发固定方案的平均误差更低，且在本次随机对照中有优势。**不能证明普遍泛化、全局最优、变异优势、三画像优势、独立传感器融合或真实下游模型收益。** 下一阶段应以更多未参与调试的时段/区域及独立观测源检验稳定性，不能把第四案例的负结果删掉。
