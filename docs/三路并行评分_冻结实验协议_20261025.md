# 三路并行评分：实现与冻结实验协议（2026-10-25）

研究问题：三画像能否在不读取隐藏目标真值时形成有区分力的组合评分；评分是否改善验证搜索和独立时空案例的选择效果。

## 公共实现

复用 Composition、注册算法、Reconstruction 的观测算子、现有场景风险函数、SearchValidation 和 ALNS。新增 composition_scoring.py，由公共 composition.parallel_scoring 配置启用，文件、页面处理器和 CLI 共用。保留旧实验与旧评分路径。

三路并行评分均在 [0,1]：

1. 数据适用性 D=1/(1+e/s)。e 为输入中可见细网格内部锚点被遮挡后的实际重建 RMSE；s 为这些可见锚点的空间标准差。它是当前数据上的自监督适用性证据，不是未知目标的真实误差预测。
2. 模型适配性 M=(1+U)/2。U 复用模型场景的加权风险下降，评价真实探测输出的粗观测一致性和细节保留。场景的阈值和偏好是明确的工程要求，不冒充 WRF 运行敏感性。
3. 组合协同性 C=(1+(b-e)/(b+e))/2。b 是当前组合各自完整单源分支在同一探测点的最低 RMSE；e 是完整融合和后处理的 RMSE。b=e=0 时定义零收益。这个指标识别“优于当前组成分支”，不宣称超过整个库最强单算法。

联合 S=wD*D+wM*M+wC*C，权重非负归一。未知项维持 [0,1]；按下界保守排序，不将缺测填成零误差。该上下界表示支持范围，并非统计置信区间。

每个时段在其可见内部细网格锚点上做遮挡，执行完整局部处理链，更新真实前后状态，因此去噪与插值顺序、融合后滤波均进入响应。无夹持锚点、无法测量或契约不支持时保持未知。跨时段交互不由局部探测推造，最终完整图仍经过原有协调检查。

先对所有合法组合做三路联合评分，再选初始图和变异。若提供独立 SearchValidation，最终变异目标仍为真实验证 RMSE；没有验证标签时按评分推荐。探测不接收 SearchValidation 或最终测试标签。

## 数据与隔离

NCEP 真实温度场的受控互补分辨率构造；并非独立传感器。每例 33 个六小时时次，8×8 细源仅提供五个 48 小时锚点，4×4 粗源提供全部时次；评价另外 28 个细网格时次。

两个固定时段各 36 种局部策略，共 1296 种完整图；先后顺序、逐源分支、主辅及后处理均包含。每个时段探测 36 张局部图，总计 72 次真实局部执行，不能当作零成本初筛。

四个区域的格点索引范围见 output/parallel_portrait_20261025/protocol.json，互不重叠。开发采用两个西部区域×四个2013年时段，共8例。验证采用四区域×两个2014年时段，共8例；各自使用后续不重叠日期作为最终测试，共8例。两个东部区域不参与权重拟合。时间、区域分别存在重复结构，不能将全部种子视作独立样本。

权重只在开发组小型单纯形网格上校准：全机制使用等权及 (.5,.25,.25) 的三种排列；逐路消融使用剩余两路的 (.25,.75)、(.5,.5)、(.75,.25)。目标为初始两张图的开发相对遗憾均值，并记录留一案例诊断。该校准只修改三路权重，不训练另一套排序器。开发固定方案从全部1296张图的跨开发平均 RMSE 选择；另保留36张不分时策略中的最强固定。

## 对照与验收

全三路、分别移除数据/模型/协同一路、无评分ALNS、纯随机、给予104次完整目标执行的随机、仅评分推荐。除额外随机与仅评分外，均32次唯一完整执行、128次提议；种子11、29、47。无评分初始化仅为显式实验消融；正式三路机制始终先完整评分后变异。

探测的72次局部执行与正式目标执行分列，累计核调用和墙钟均保留。额外随机给予32+72=104次完整执行，这是计算量敏感性对照；局部单时次探测和完整28时次图的成本不同，不能将两者等价后声称严格等时加速。

所有开发与验证案例全域真实执行，提供有限域验证最优参照。所有方法的选择及权重冻结后，才计算最终测试误差；禁止根据最终测试修正评分。固定、随机、消融、失败种子及负结果全保留。

验收包括：

- 真实响应证据、候选分数区分度、未知场景保持未知；
- 受控改变数据或模型偏好，公共入口对应推荐发生变化；
- 无隐藏参考仍可推荐，改变独立测试标签不会改变推荐；
- 相关旧模块回归、文件/页面处理器/CLI一致；
- 独立回读保存产品与标签重算误差、分数及选图；
- 报告按案例平均的最终测试RMSE、相对固定差异、描述性案例自助区间、消融和验证命中率；不以测试优越性为必须成功的验收条件。

原始准备阶段曾有一次日志打印参数位置错误，尚未运行科学实验；失败日志和当时源码保留，修复后重新冻结。测试临时目录权限问题及测试构造中的重复注册/不具冲突的初始样例同样保留记录；机制测试改用有明确源偏差的受控冲突样例，未根据正式数据成绩改规则。
