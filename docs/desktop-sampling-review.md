# 桌面工作台的抽样和本地回检

数值补证按已审核字段取少量样本。多个 NetCDF 文件共同补证时，在本轮预算内轮流覆盖不同文件、物理变量和已声明频率。网格只读选中的块，NetCDF 优先用时间坐标识别不同频率。超长时间轴在首轮只看局部窗口，正式回检时分块核对完整时间坐标和时间区间。保留的后段时间、站点和空间块只用于本地回检。月度回检检查末月内的转换或插值重建，不给未来预测精度评分。

## 为 CSV 或 TSV 加速定位

没有索引时，推荐阶段只读有限的前段记录。正式回检按站点或月份在预留范围内做分层蓄水池抽样。需要核对最后一个月时，本地回检阶段再顺序扫描，以确认该月没有参与推荐。也可以事先建立持久索引，加速按站点或月份直接读取。

```powershell
python -m ecodata.desktop.csv_index 'D:\data\weather.csv'
```

索引会生成在输入文件旁。平台按文件大小、修改时间和表头核验索引，源文件变化后需要重新建立。索引不进入 DeepSeek 请求。

## 指定独立参考栅格

在输入目录下建立 `sampling-references.json`。键和值里的路径均相对输入目录。

```json
{
  "rain.tif": {
    "reference": "checks/rain-observed.tif",
    "band": 1,
    "baseline": "nearest",
    "spatial_semantics": "cell_mean"
  }
}
```

基线可以设为 `nearest`、`bilinear` 或 `conservative`。保守重网格需要同一坐标系的规则网格及明确的 `cell_mean` 或 `flux` 语义。两种结果使用同一独立参考网格和同一组有效像元计算 RMSE 与 MAE。参考文件和清单只在本地使用。请指定独立观测产品，并在两侧声明匹配的单位。缺少参考或共同有效像元时，界面显示待核实。

## 扫描版 PDF

优先使用本地 Tesseract，Windows 上也可使用系统 OCR 和已安装的识别语言。文本会附页码供核对。识别不清的单位、符号或页码相关证据应回到原页确认。

## 放行和追加证据

推荐卡片会显示本地回检是否放行。降水率积分要用明确的时间区间试算，空间转换要通过留出网格验证，表格数值列要确认单位。执行前校验原始文件签名并分块检查时间、单位、缺失与无数据掩码。工程说明可在推荐页按章节复查，清晰的观测表可以另存为本地 CSV。

只有采样覆盖不足的方案才会显示追加证据入口。优先发送少量补样。仍需全量且确认权限后，平台先生成获准连续数值字段的扰动副本，并显示发送字段、记录数、大小和分片数。表格标识、分类编码和未选定字段保留在本地。副本用 CSV 分片和清单保留位置、掩码与必要结构，归档内部按原成员路径组织。批准后，每个分片通过单独的 DeepSeek 请求发送并记录回执。

全量分片的回复供补充判断。已发给 DeepSeek 的数据无法继续作为同次独立回检集，执行仍需独立依据和原始数据检查。
