# 外部已有WRF工程：当前接入边界

此入口位于“自定义WRF工程（试验）→接入用户上传的外部工程（试验）”。支持先检查、后显式启动受控运行；原有本机成功任务号接入与登记案例路线继续保留。不能将限定科学配置通过写成任意工程通用。

## 两套不同依赖

- 原生WRF初始/边界输入：用户明确选择WRF目录的namelist.input，其同目录的wrfinput_d01、wrfbdy_d01；另选REAL配置，不自动猜选或生成。检查单网格、日期、初始维度和明确的thisbdytime/nextbdytime边界区间。wrfbdy的Times可能只有一个区间起点，不能据此判定只覆盖一个时刻或推断终点。
- 替换平台气压场还需：namelist.wps、geo_em.d01.nc、各时次完整WPS intermediate-v5场，内含原湿度、地表、土壤等记录。四个TT/UU/VV/GHT转换变量不能代替这些资料，wrfinput也不能自动反解为完整原始WPS工程。

读取ZIP不解压执行；256MiB压缩/展开限额，2000文件限额，拒绝重复、穿越和符号链接。上传程序/脚本只列名，绝不调用。完整WPS资料与本次转换齐全时，对每个时刻调用既有assemble_pressure_update，检查原气压层集合、单位、风方向及精确坐标匹配，不插值、不补造、不回退示例。报告明确native_model_executed=false。

工程识别和合并兼容性不代表运行验收。新增受控运行仅接受WRF4.8.0、已审核的单网格CONUS科学设置与受控静态表；不同physics/dynamics/同化等设置以及未知参数被拒绝，不被覆盖。几何与时段等明确字段允许在限定资源范围内不同，REAL/WRF的科学及网格设置必须一致。两份配置逐字节写入新目录，运行后复核SHA256一致，不通过平台外脚本修改参数或补文件。完整WPS与新场按原引用前缀合并，调用已安装的metgrid、real、WRF并出图。
