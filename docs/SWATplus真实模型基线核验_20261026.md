## 2. 确实运行了什么

- 原生程序：SWAT+ Revision59.3；控制台与新生成输出文件均显示该版本。
- 真实流域：美国Little River Experimental Watershed的gauge J上游工程；131个HRU、3段河道、3个塘库。
- 原有模拟期：2000-01-01—2012-12-31；原有预热3年。
- 初次原样运行：`runs/lrew_original`，退出码0，明确输出`Execution successfully completed`；原工程仅开启流域年度水量输出，未开启河道输出。
- 可评价运行：`runs/lrew_verified`，仅将`print.prt`的channel日/月/年输出开启，其他93文件中的所有非print输入逐个SHA256核对一致。没有调整物理参数、管理、天气、时间和预热。
- 独立复跑：`runs/lrew_repeat`，退出码0；日、月、年河道输出和流域年度水量输出与前次逐字节一致。
- 新生成三段河道共10959条日输出，其中出口3653天，2003-01-01—2012-12-31连续、无重复、非恒定、无负流量、数值有限。标准错误为空，diagnostics.out仅标题。

出口依据`channel.con`的路由关系确定：2、3汇入1，1没有下游连接；选择1不是通过逐河道拟合观测决定的。空间层也显示对应河道和塘库关系。没有把上游下载包内缓存输出当作新运行证据，运行目录在执行前无`channel_day.txt`。

## 3. 单位、缺测和观测对齐

本版`channel_day.txt`头部把`flo_out`标为**ha-m**，代表当日体积，不能直接当m³/s。转换为`flo_out × 10000 / 86400`，再与观测日均流量比较。

观测单位m³/s由[SWATrunR源文档的Observation data说明](https://github.com/chrisschuerz/SWATrunR/blob/master/vignettes/SWATrunR.Rmd)确认，源文档已下载保留。该文档其他示例的模型版本和河道结构与本工程不同，没有照搬其河道编号。RDS用成熟`rdata==1.1.0`读取，R Date的日数按1970-01-01转换，所得首尾日期与上游文档一致。解析器对R类的回退提示已保留，不表示日期自动被正确解释；本次显式做了转换并校验覆盖期。

模拟期4749天，各气象文件日期连续。降水`lrew137.pcp`有7个、`lrew146.pcp`有4个`-99`标记，`lrew138.pcp`没有；同期间温度、辐射、湿度、风速没有`-99`或非有限值。本轮没有人工补值，保留带WGN的原工程默认处理。**尚未逐日追踪这11处标记对应的模型内部补值，不将其当成实测降水。**未来强迫扰动比较需要统一并显式处理这部分。

观测16437条为有限非负值；评价期3653天全部能对齐。仓库RDS未提供逐日质量旗标，本次只能核验可读性、覆盖和基本数值，不能声称已完成原始测站质量复审。

2. 因此，**本次成功仅认证SWAT+59.3和配套LREW工程，不能外推为现有平台62.0.0写出器已获原生验收。**后续需要匹配62版完整工程并核对适配器；当前可冻结59.3作独立模型调用基线。

5. 尚缺与本流域、同期相配的独立“低时间高空间”和“高时间低空间”双源强迫数据，以及预先冻结的正式融合分割/扰动方案。本次配套站点资料不等于已准备好这一正式多源实验。
