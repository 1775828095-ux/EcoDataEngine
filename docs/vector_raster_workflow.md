# 矢量转栅格操作

上传包含 .shp/.shx/.dbf/.prj 的 Shapefile ZIP，或 GeoJSON。选择 GeoTIFF、NetCDF 或 HDF5-NetCDF 时自动采用矢量栅格化。

自动识别 CRS、Point/LineString/Polygon 等几何类型、真实要素范围及属性字段类型。无需填写坐标字段、输出范围或行列数；已有 CRS 只展示，不要求重复填写。缺少 CRS 时仍须确认，不能猜测。

数值属性自动推荐，可在“栅格化字段”中切换。字符串、标识符和含缺失值的属性不作为默认栅格值。没有合适数值属性时，自动输出 value=1 覆盖掩膜、单位 1；范围外和未覆盖像元为 NoData，不生成虚构观测值。原始属性不被修改。

目标分辨率采用源 CRS 单位：投影坐标通常为 metre，地理坐标为度。这里不自动重投影或把度当作 km。输出范围向外补齐完整像元，真实像元尺寸等于所填分辨率；点或水平/垂直线等零宽高范围自动扩展至至少两行两列。超过 200 万像元时提示增大分辨率数值。

选择“像元中心”或“所有接触像元”。点、线按 Rasterio 对应规则绘制；小多边形可用所有接触像元避免遗漏。属性栅格化的重叠策略默认报错，也可明确选择先/后要素优先；掩膜重叠保持 1。

点击执行，下载结果和 JSON 报告。报告包括识别信息、输出范围、行列数、策略、掩膜状态及历史；GeoTIFF 额外检查宽高、波段、CRS、transform 和有效像元。
