# Robit＋ERA5：已有变异机制接入与补跑交付

日期：2026-10-28。正式证据目录：`output/robit_era5_mutation_20261028`。

## 1. 交付结论

**变异已实际接入平台公共入口，自动选图、执行、可见值自验证和天气输出链路均通过验收；这轮效果没有取得优势。**

本轮使用既有ALNS库与AlphaUCB算子选择、HillClimbing接受机制，补开放DAG适配，没有改用上一轮开放枚举，也没有用GOLEM代替变异。初始候选先计算三画像分，再进入真实执行和变异；每个子候选保留父图、编辑、评分、执行及接受/拒绝记录。

测试平均年度RMSE：ALNS为 **8.3133 mm/day**，比相同初始化但不变异的8.3742改善 **0.73%**；比开发期最强固定8.1255差 **2.31%**，比同邻域随机8.0958差 **2.69%**。因此只能确认变异和自动处理机制实际工作，不能宣布智能选优、三画像指导或变异搜索已获得效果优势。

## 2. 平台现在如何自己判断和处理

公共模式为`PortraitMutation`。页面薄客户端、`submit_search`和`submit_file_request`共用服务，流程如下：

1. 识别真实文件、变量、时间、单位、物理语义和源身份；缺少或冲突的必要语义不能猜填。
2. 根据明确的模型/角色/字段/任务加载已注册模型策略；只有唯一匹配时自动加载对应属性注册表。有歧义则明确报错，不替用户猜模型偏好。
3. 从全部注册实现生成实际根节点邻域，按父节点契约过滤、计算三画像状态风险减分。未处理原始源也可成为候选，避免强迫组合。纯非负投影对已经非负的输入为可证明恒等，保留日志并跳过。
4. 真正执行初始化图，以共同验证目标选出初始最好图。算法上下文不含验证/测试标签。没有外部标签的逐日点序列，从原本可见值构造遮挡并从输入移除，自动形成搜索验证集；这是自验证，不是未知真值精度认证。
5. 调用已有ALNS：算法替换、参数修改、插入/删除节点、重连源/中间分支、交换相邻单源步骤。主辅角色和权重由已注册融合参数表达，逐源分支可以不同；没有手写完整图池或固定图深度。
6. 每个新图交给真实DAG执行器；未知下游契约在实际执行中核查，完整输出才有RMSE。ALNS按真实验证目标反馈算子收益，保留历史最好图，最终验证误差不劣于初始化。这个性质不保证测试效果更好。
7. 用冻结图处理数据，恢复原可见观测，导出并回读天气文件。

代码落点：`src/ecodata/algorithms/field_mutation.py`负责开放图适配；`composition_optimizers.search_graph`复用既有ALNS控制；`composition_decision.score_state`由原评分方法原样抽出供两入口共用；`platform_search.py`和`interface/search_page.py`接公共模式。未修改本轮算法数值内核。

与旧有限分类轴ALNS的区别是搜索状态改为实际DAG，因此必须增加节点/连接编辑适配，而非直接把旧四十图或开发发现的591个配方当全库。空邻域不返回父图冒充同分成功；同分接受可探索，但AlphaUCB不奖励同分（奖励[5,2,0,0]）。已有有限轴入口保持原行为。

适用边界：本轮证明的是Robit逐日降水任务。没有参考的通用二维场尚不能使用这个逐日点序列自验证器；不能声称任意数据、任意模型都能无人确认全自动处理。SWAT+真实响应和未测量偏好仍是UNKNOWN。

## 5. 不能掩盖的问题

**事实一：初筛缺乏区分度。** 9次ALNS的32个兼容初始算法候选都只有一个画像分区间；另外两个原始源候选独立计分。大量序列算法的执行前效果缺少已核实响应，评分器依照要求保留UNKNOWN，没有人为补“擅长程度”。因此本轮三画像初筛没有实现有依据的差异化排序，不能因公式被调用就宣布选优有效。

**事实二：变异真实发生，但存在图膨胀。** 1237条ALNS父子评估记录中，重连342、算法替换317、参数201、插入200、删除147、顺序交换30。最终有两图达到37和40个算法/校验节点（不含原始source）；它们不是37或40种独立科学方法，包含大量重复恢复、时间对齐和校验步骤。

**事实三：多数选图未采用双源处理路径。** 9张最终ALNS图仅2张在算法图中同时连接source0和source1；其他选择站点单源或ERA5校正等分支。原值保护仍把可见站点保留在最终天气产品中。不能把同一ERA5的两个校正版本算两份独立数据，也不强迫所有案例必须融合。

**事实四：随机对照更好且更快。** ALNS的验证改善事件随机修复6次、画像修复4次，二者次数不等、不是随机分配消融，不能直接作因果归因。结合初始同分、失败与缓存比例、图膨胀，可以提出“画像响应不足、编辑效率低、同分游走占用预算”等待检验解释；尚不能仅凭本轮确定各因素贡献。
