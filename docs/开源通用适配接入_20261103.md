# 开源通用适配组件核查与最小接入

本次只修改独立 existing_air 转换包和测试，不修改融合/随机搜索策略或页面，不更改用户原始数据。基于889cabf后的本地修改；未推送、未替换D盘运行实例。

## 官方项目与取舍

|项目|许可|本项目实际采用/判断|
|---|---|---|
|[h5netcdf](https://github.com/h5netcdf/h5netcdf)|BSD-3-Clause|调用其HDF5/NetCDF4读取后端，通过Python二进制流传文件，绕过Windows路径被传入NetCDF-C的问题；复用现有依赖，未拉取执行上游脚本|
|[xarray](https://github.com/pydata/xarray)|Apache-2.0|保留现有解码语义，按真实签名选择h5netcdf或SciPy后端，关闭文件句柄后返回已加载数据|
|[CF-xarray](https://github.com/xarray-contrib/cf-xarray)|Apache-2.0|现有scientific_schema已调用坐标发现，不重复包装为新接入；依赖正确的CF元数据，不能创造缺失单位/CRS|
|[f90nml](https://github.com/marshallward/f90nml)|Apache-2.0|现有project_binding已使用，依赖声明已存在；不能据此宣布完整工程科学契约验证|
|[HydroMT](https://github.com/Deltares/hydromt)|MIT|官方说明以水系统空间模型及其插件为重点，已列插件并非本项目五模型通用适配器；没有找到可直接套用的五模型插件证据，未引入依赖或替换平台|

查阅的是官方README、仓库元数据与许可证；检索到框架不等于其能够读取任意模型工程。源码许可证未被改动，使用已安装发行包的公开API，没有拷贝上游源码。实际安装版本可通过importlib.metadata核查，GitHub默认分支HEAD仅为调研快照，不是本次安装版本。

## 修改

- integrations/existing_air/existing_air_converters/netcdf_io.py：公共load_dataset，HDF5签名用h5netcdf，CDF1/2用SciPy。未知、损坏或CDF5明确失败，无静默换算法/补值。
- cmaq_reviewed.py：三份实际卫星/气象/网格输入改用公共读取函数。
- calpuff_fusion_stage.py、calpuff_native_bundle.py：中间产品读取改用公共函数。
- integrations/existing_air/pyproject.toml：声明所调用的xarray/h5netcdf/h5py/SciPy依赖，与主项目范围保持一致。
- tests/test_native_netcdf_stream_io.py：中文路径、CF缺失值/打包解码、三种格式、非法输入与原件不变检查。

## 验证与边界

22项读取及工程绑定回归通过。3份真实CMAQ输入在中文路径读出，与独立netCDF4内存读取器的xarray数据、坐标和属性assert_identical通过，源文件哈希不变。

中文路径整链复验：CMAQ已通过新读取入口和融合选择，仍在原生转换的netCDF4.Dataset(source)处失败。原生更新器要求保留文件格式、编码与非目标变量原始数据，不可直接用h5netcdf重写取代；该阶段尚未修改。

CALPUFF数据准备通过，新读取入口已工作；沙盒中后续原生子进程报DLL错误，授权环境中文路径复验最终CONVERTED，原件哈希不变，CALMET/CALPUFF实际运行记录在converted/native_run.json。不是所有陌生工程通过，也不构成预测精度验证。

证据目录：工作区 自测889_20261103/。opensource_tests.xml/log、real_netcdf_io.json/log、GitHub候选组件来源.json、*_opensource.json/log、calpuff_opensource_authorized.json/log。

当前未解决：无单位/CRS原始资料自动解释、任意版本/工程网格的科学一致性、CMAQ中文路径原生写入及独立回读、全部陌生工程通用性。库接入仅解决所测输入读取兼容，不能宣传全五模型通用接入已完成。
