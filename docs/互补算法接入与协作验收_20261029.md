# 互补算法接入与协作验收（2026-10-29）

本轮完成算法库补充和公共入口连接验收，未重跑正式效果实验。目的为增加可协作的处理环节，而非继续增加同类插值算法。

## 接入内容

|公共注册ID|用途与搭配关系|实际后端|
|---|---|---|
|`bias.xsdba_scaling`|使用历史配对数据校正均值偏差，再与重建、融合节点配合；复用原有训练/调整子进程|xsdba 0.5.0 Scaling|
|`spatial.denoise_tv`|TV空间去噪，降低噪声后再重建或融合|scikit-image 0.26.0|
|`spatial.denoise_bilateral`|利用空间距离及数值差异进行双边去噪，是TV的可替代选项|scikit-image 0.26.0|
|`spatial.wavelet_lowpass`|提取低频背景，可作为融合前的独立步骤|PyWavelets 1.10.0 SWT|
|`fusion.wavelet_detail_transfer`|两源已对齐后，结合一源低频背景与另一源空间细节|PyWavelets 1.10.0 SWT及本地组合公式|

新增五个可调用节点，覆盖偏差、噪声、多尺度融合三个角色。TV与双边在去噪角色中互相替代；协作价值来自不同角色的配合，不要求五个节点全部采用。它们与已有时间插值、空间重网格、补缺、锚点残差和物理范围投影共用接口。

均值校正采用官方Scaling：加法形式为 `x + mean(reference_train) - mean(history_train)`；乘法形式为 `x * mean(reference_train) / mean(history_train)`，零分母拒绝。小波融合为 `L(background) + alpha * (detail_source - L(detail_source))`，其中L为db2平稳小波低频重建。它不是STARFM，也不保证粗源守恒或产生真实原生高分辨率信息。

## 平台如何使用

节点注册在默认算法库，空间与多源公共任务均能发现；沿用现有画像、合法性检查、随机变异、科学状态去重、真实执行和质量门。没有另建整图候选池、加入人工优待分数、替换现有评分器，或强迫优化器采用某条路线。

参数提议来自独立空间帧的噪声估计、图像大小允许的小波层数及随机变异。新增响应的精度收益、守恒和范围保持仍标UNKNOWN；本轮没有凭算法名称编造效果画像。最终是否值得使用，仍须在隔离的验证/测试实验中检验。

要求有限、规则、至少8×8的连续变量栅格，保留明确单位、物理变量和CRS；两源融合还须物理含义、坐标和时间严格一致。缺失恢复、时间对齐、重网格必须由各自节点负责，不能在新节点里悄悄补齐。TV/双边逐帧处理，不混合时间。双边调用前统一数值尺度，结束后恢复物理单位。

校正要求历史配对参考，不使用测试真值；历史和应用数据必须使用一致的前处理状态。可以先去噪再校正，但训练历史也必须经过相同去噪，不能拿原始分布拟合的校正器直接套用。发现并修复xsdba栅格输出维度顺序问题，统一恢复输入维度顺序。

## 验收证据及边界

- 定向及公共模块回归：最终60项通过；另外原有EQM/DQM/QDM三种xsdba回归此前已通过。最终XML与日志在下述目录。首轮双边单位一致性失败及修复前产品保留，未删除负结果。
- 自动组合：测试由现有GraphMutation生成含小波融合和去噪分支的图，再经公共无标签部署入口执行；五个新增节点均有真实调用记录。另经公共随机变异搜索完成机制验收。这里验证可达性，不证明优化器更优。
- 真实输入：复用2013—2014历史训练与2015开发数据，16×16窗口、10个时刻，公共入口完成11次注册算法调用，五个新节点均执行成功，可见原始观测保持不变；未读取2018留出真值。该固定连接图仅用于接口验收，不是搜索模板或预设最优路线。
- 独立回读重放：保存的配置重新送入公共入口，输出数值及坐标与保存产品核对一致；调用台账逐项PASS。科学优势明确为NOT_EVALUATED。
- 页面点击流程未单独操作验收；本轮验收平台公共文件/API入口及其共用搜索、执行链。

证据目录：`output/complementary_library_20261029/`。重点文件为`test_results_final.xml`、`algorithm_profiles.json`、`real_data_acceptance.json`、`independent_audit.json`、`real_2015/mechanism_config.json`及各部署调用台账。原正式实验目录未重写，旧结论仅对应其冻结版本。
