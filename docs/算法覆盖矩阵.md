# 算法覆盖矩阵

状态：**可用**=项目中已执行验证；**候选**=官方实现存在但本项目尚未验证；**不适用**=物理语义或输入条件不匹配；**暂缓**=源码/许可/环境阻塞。

| 数据/任务 | 传统与现有算法 | 先进算法候选 | 当前判断与缺口 |
|---|---|---|---|
| 30m FVC 连续栅格 | 双线性、QP（有约束/观测时）可用 | Thera、自监督候选 | Thera 自然图像权重不能直接证明 FVC 可用；需训练/真值或粗尺度一致性验证 |
| 30m 土地利用分类 | 最近邻、类别比例/多数类 | Galileo 可提取部分官方类别特征 | 不使用连续超分；Galileo 不是分类重采样替代品 |
| 30m DEM/坡度 | 面积统计、地形特征；Galileo SRTM 编码已可用 | Galileo 后接任务头候选 | 当前只得到特征，尚未验证 DEM 重构精度 |
| 500m LAI/NPP | 双线性/保守方法依变量语义 | Thera/Galileo 仅候选 | 不在 Galileo 官方预训练变量组；需专门适配和独立真值 |
| 1km 气温 | 双线性、Kriging、QP；现有 FNO/UNO 在适配后可用 | Granite WxC 候选 | 官方已有 MERRA-2 2m气温 6×权重；其他产品/变量不能直接复用 |
| 1km 风场 | 矢量分量一致的重网格 | Granite WxC 候选 | 官方 ECCC u10/v10 示例；需产品、网格和变量兼容检查 |
| 1km 降水 | 保守重采样、Kriging、QP | PRIMER 候选 | 总量守恒、零膨胀和极值需专门处理；PRIMER 许可/算力阻塞 |
| Sentinel-5P 高光谱 | 传感器感知重采样 | 2026 自监督 SR 候选 | 需 S5P 退化算子和 SNR；不能改名为通用环境超分；许可未明确 |
| 普通光学遥感影像 | 双三次基线 | Thera 候选；DIIN 暂缓 | 需匹配传感器、波段、动态范围；DIIN 无代码 |
| 多源遥感+地形+气象特征 | 现有加权/残差融合 | Galileo 特征编码已可用 | 已接通编码器，但预测头、跨尺度融合和独立验证尚未完成 |
| PM2.5背景场+站点+气象 | IDW、Kriging、QP、偏差校正、FNO/UNO/观测引导 UNO | Galileo 只能为官方辅助变量提供特征；PRIMER机制可借鉴 | 不能直接套降水模型；应先做偏差校正、观测守门和独立站验证 |

## 回退原则

- 算法依赖、权重、变量或验证条件不满足时，回退到与变量语义相符的最近邻、双线性、保守重采样、Kriging、QP或现有融合算法。
- 回退必须写入处理报告；不能把插值结果标成 Thera/Galileo/PRIMER。
- 没有独立高分辨率真值时，只报告结构、粗尺度一致性、守恒和稳定性，不声称空间精度提高。
