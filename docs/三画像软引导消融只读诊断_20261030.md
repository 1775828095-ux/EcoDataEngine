# 三画像软引导消融只读诊断

范围：只核对本轮源码、已封存产品指标、逐种子搜索轨迹和折输入指纹。没有修改生产代码、政策、输入或既有结果，没有执行新的候选图。核对source_manifest.json，生产源码指纹变化为0。

## 判定

本轮full与no_portraits差异主要是搜索提议/实测锦标赛及其成本、随机数消耗、停止节奏，不是两套不同的三画像最终排名。历史支持存在不足，但两组共用相同历史输入，不能把组间差距单独归因于历史不匹配。没有证据证明三画像普遍有害。

### 1. 实际评分没有关闭，也没有额外产生画像辨别力

两组权重均RMSE=1，归一化尺度逐任务相同，简约容差均0，历史主评分和当前局部诊断划分相同。score_interval=1/(1+objective)，只是已有误差的单调变换。49个同种子、同任务共同计分图的objective逐一完全相等；六对初始图及初始分数相同。历史折ID包含request的mode而不同，但对应输入SHA和日期相同，不能把ID不同误报为数据不同。

代码：reliable_selection.py:95、106、115、215；dag_response.py:93；field_mutation.py:712。

两组都按自己的实测误差和既有近等价排序选图，未发现把已评分的明确更优图丢弃的证据。full没有实际执行到对应no_portraits最终图的完全相同结构/参数，六对均如此；这不排除已执行其他近等价科学状态。

共同强参照在六个full任务中均因“至少四个真实可见网格点”契约失败而UNKNOWN；没有可用的共同参照增益。代码也不把该增益加回误差，故不能把它描述为本轮发挥作用的额外收益引导。

### 2. 所谓画像引导实际是有成本的随机小锦标赛

field_mutation.py:620随机抽最多3个合法变异，真实执行，用同一误差择优；其余已执行候选仍保留档案，不是丢弃两个输家。关闭后每次直接随机选1个。它不是根据未执行图的条件画像预测哪个变异更有希望。

六次full共有353个有记录的变异步骤、489次mutation_probe；no_portraits为653步、0次mutation_probe。算子调用3973对3722；不能说full因花费更少或纯粹预算不足而败。full有时评了更多图，但同一邻域多试、少做下一次随机变异，搜索覆盖和随机数序列都变了。

旧停止规则按新增数值评价计停滞，阈值86次、相对改善约2.918%。锦标赛的多次探测会一起消耗停滞计数，同一阈值下两组可进行的变异步骤不同；六组均因NO_MATERIAL_VALIDATION_GAIN停止，不是超时。该政策来自2015开发分布，并未针对这次多折锦标赛重新证明适用性。不能把它直接认作确定的因果主导因素，需后续受控消融验证。

### 3. 差距集中于两个搜索种子，并非每次去掉都好

双方各赢3次；分散29与连续47解释超过全部净均值差距（其他配对部分抵消）。这两对no_portraits不仅测试更好，内部历史目标也更低：0.48389166对0.49286659；1.13012566对1.18576471。因此这两个主要差距首先是full未找到同等好的内部候选，不是已找到验证更优图后专门在测试上反转。

### 4. 历史匹配确有风险，但本轮消融没有隔离它

development_validation.py:103检查传感器，检查物理定义、单位并匹配可见/隐藏数量，120按日历距离最小作单调日期匹配。它没有基于可见物候/地表组成/粗源动态相似度决定是否适用，没有日期偏差拒绝门；2020与2021病例仍等权。

Kansas任务对应历史日期最大偏差39天和13天，采样间隔差异最大39天和23天。真实连续缺口隐藏日期跨80天，左右锚点跨度160天，数量相同不等于动态条件相同。

有历史病例时，field_mutation.py:712直接把历史折作为objective；当前局部折只要求数值/质量有效，不用其误差做排序或明显退化否决。可以判断历史适用性控制不充分；不能由此断言历史信息无用或量化它造成了多少测试损失。

fold_only误差0.05789672低于full的0.05996978，仅是提示：它同时关闭画像引导、删除历史主评分并减少每图验证成本，不能当作纯历史消融。

## 后续应验证的改动方向（未实施）

把“同一评分能否正确排名”与“锦标赛是否改善搜索覆盖”分开：同图库比较；同一提议序列与真实调用成本下比较；停止机制按多折/探测成本单独检查。历史病例增加可见数据的适用性判定，再测是否应担任主评分；保持未知、避免硬塞模型偏好。不能仅继续加预算或用这次Kansas测试反复校准直到获胜。
