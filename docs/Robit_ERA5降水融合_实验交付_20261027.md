# Robit＋ERA5降水融合实验交付

实验批次：20261027；交付核查：2026-10-28。正式结果为V6，早期诊断不并入正式效果。

## 1. 结论

数据输入、公共平台自动连接算法、真实数值执行、遮挡评价、SWAT+天气格式输出已跑通。新增第二来源ERA5后，自动方案相对开发期选择的站点单源恢复，测试平均RMSE降低 **3.36%**。改善集中在连续缺口；随机单日遮挡没有改善。

但自动方案略差于开发期最强固定融合 **0.04%**，相对随机探索仅好 **0.18%**，均无可靠优势。相对站点单源的年度配对改善区间也跨零。因此，本轮提供了补充降水源对缺口恢复可能有用的证据，**未证明自动组合优于固定方案或随机搜索，更未证明全局最优、遗传变异创新或SWAT径流收益**。

原始站点降水完整。本轮恢复人为隐藏的已知日值，不声称把完整原始观测融合后就更准确；交付的天气版本为遮挡恢复试验产品。

## 2. 第二来源、时空范围和独立性

队友Robit站点：北纬11.6°、东经37.36°，1990—2013年日数据，共8766日。复用现有Robit原始天气文件，降水、最高/最低温、辐射、湿度、风速均有值；其他变量不参加本次融合。

新增ERA5 total precipitation，经Open-Meteo Historical Weather API明确指定`models=era5`，覆盖同一1990—2013时段。请求站点位置，最近格点返回北纬11.5°、东经37.25°，距离约16.32 km，原生网格约0.25°。这是覆盖站点的格点平均估计，作为站点代理使用，**不是同位置第二台雨量计，也不是精细空间观测**。坐标、空间支持、单位、请求参数及原始JSON/CSV、下载回执与SHA256均保留。[API说明](https://open-meteo.com/en/docs/historical-weather-api)

ERA5降水并不直接同化本地区雨量计日降水；文献所述美国雷达/雨量计复合资料例外不适用于埃塞俄比亚。然而Robit原始天气的生产谱系尚未核实，因此只能说是不同生产链来源，不能保证二者完全统计独立，更不能将ERA5视作独立地面真值。[ERA5降水评价](https://rmets.onlinelibrary.wiley.com/doi/10.1002/qj.4351)

主方案按当地UTC+3日界累计；Robit日界未注明，这是显式假设。另在评价前下载UTC版本作日界敏感性检查。两者是同一来源的不同日界，不能当两个独立源。降水数值是24小时累计mm，接口标记mm/day，不额外除以24；执行时依据区间边界对齐。[ECMWF累计字段说明](https://confluence.ecmwf.int/pages/viewpage.action?pageId=111150607)

训练期同日相关系数约0.489，说明来源并非逐日高度一致。测试UTC原值RMSE为8.3380，主UTC+3为8.4878；保留日界不确定性，不事后更换主方案。下载仅发送位置与时间，没有上传站点值。

## 3. 信息隔离与遮挡

| 时段 | 用途 | 可接触的信息 |
|---|---|---|
| 1990—1995 | 拟合 | 月统计、ERA5先验校正及需要训练的既有方法 |
| 1996—2001 | 开发 | 发现候选配方、选择固定方案及单源基线 |
| 2002—2007 | 验证选图 | 平台按真实恢复误差选图；随机对照相同预算 |
| 2008—2013 | 最终测试 | 48份预测冻结后才读取隐藏标签计分 |

随机单日、连续3日、连续14日三类遮挡，每年目标约20%，位置不依据降水大小选择。连续整块造成实际数量略超目标；测试分别438、450、504个隐藏日。它们是三个重复遮挡情境，日期可能重叠，不能相加当独立样本。

每个情境的站点输入同时移除开发、验证、测试全部隐藏值。ERA5保持可见；算法拟合仅有训练期配对数据与状态。隐藏站点值只进入对应阶段评价器，测试参考文件不在算法输入列表。允许历史缺口两侧可见观测，因此不是实时预测。平台恢复后精确保留原可见站点值。

主指标：各测试日历年隐藏日RMSE，先等权跨年，再跨遮挡情境及搜索种子平均。附报MAE、Bias、湿日命中/虚警、强降水误差；强降水阈值取训练期湿日90分位30.21 mm/day。6个年份为分析块，遮挡情境和种子不是新增独立样本。

隔离指本轮拟合、选择和最终计分的访问边界。Robit本身是项目历史已使用数据，不能将其称作从未探索过的新外部盲测；后续泛化仍需新增站点或未使用案例。

## 4. 实际复用与候选空间

走公共`AutonomousField`、`platform_search`、既有DAG执行器和真实算法库；新增少量序列适配：缺失回退、绑定来源与训练期状态的先验校正、非负裁剪。复用原时间恢复、仿射拟合、加权融合和官方xsdba校正实现。新增适配器不是新科学算法。点序列不伪装为空间场。

注册库100项、78项可用，包含包装和校验项，不能称100种降水方法。按真实输入输出契约尝试单源和双源连接，包括原始/校正ERA5、站点恢复、加权融合及回退。不手写完整候选池或人为限定图深度；物理语义、来源绑定、完整有限非负输出等硬门保持。

本轮自动选择按真实验证误差，模式是开放DAG探索，**不是GOLEM/遗传变异，也不是三画像软评分消融**。这部分只回答本次平台自动组合与新来源是否有收益，不能据此归因旧机制创新。

每次180个候选实际执行、最多40000提议、120秒；种子11/29/47。开发9次，验证自动9次、随机9次。固定对照从开发实际发现的591种结构/参数配方重放，582种在三种遮挡均可完整执行，再用开发误差选择；不是拿测试最优配方回填固定方案。连续权重、开放图与资源停止意味着候选空间未闭合，591不是全部合法组合数。

开发最强共同固定方案：站点月均恢复与原值ERA5加权，站点权重约0.62739。自动选图允许退回纯单源；随机单日情境确实选出纯月均恢复，不强迫两源融合。3日与14日情境可选站点恢复与ERA5融合。图与参数逐次保留。

## 5. 测试结果

单位mm/day，越低越好。自动与随机均汇总全部三个种子，未挑最好种子。

| 方案 | 平均年度RMSE |
|---|---:|
| 站点单源，开发期选择 | 8.4112 |
| ERA5原值，主日界 | 8.4878 |
| ERA5单源，开发期选择先验校正 | 8.3502 |
| 开发期最强共同固定融合 | **8.1255** |
| 开发期逐遮挡固定融合 | 8.1526 |
| 平台自动选图 | 8.1286 |
| 同候选执行预算随机探索 | 8.1429 |

补充固定站点方法：线性9.0990、前向填充10.0813、最近邻10.2640。月均法是开发期最优站点单源，不将弱基线当最强参照。

| 遮挡情境 | 站点单源 | 自动 | 相对改善 |
|---|---:|---:|---:|
| 随机单日 | 7.5804 | 7.5804 | 0.00% |
| 连续3日 | 9.1030 | 8.5715 | 5.84% |
| 连续14日 | 8.5502 | 8.2339 | 3.70% |

自动相对站点单源赢4/6个年份；年度配对RMSE差值的描述性95%区块重采样区间为[-0.0276, 0.7296] mm/day，跨零。相对共同固定只赢2/6年，区间[-0.3416, 0.4515]；相对随机赢3/6年，区间[-0.0132, 0.0478]。样本小且同站点时间相关，区间不能作为广泛泛化保证。

自动三个种子平均RMSE为8.0942、8.1230、8.1685；随机为8.1013、8.2424、8.0851。随机最好种子优于全部自动种子的部分结果，保留原轨迹，不换种子。

次要指标也不全面占优：自动MAE约3.7849，站点单源3.9476、固定3.7935；自动强降水RMSE约39.964，ERA5原值37.825。不能把平均RMSE的小幅改善等同极端降水、湿日判别或流量模拟均改善。

## 6. 计算成本与质量核查

27次正式运行共4860次候选真实执行；4719个完整合格输出、141个仅中间状态，完整输出才参与数值目标；48900次不兼容提议保留。正式执行失败0，不等于所有尝试都合法。另有135次xsdba训练/调整调用，不能把它与一次简单NumPy运算视作同成本。

开发运行墙钟和约342秒，验证约518秒，三工作进程并行。验证自动平均37.56秒，随机19.96秒，均180候选执行；对应xsdba调用54与27次。另固定对照开发重放约125秒、1776次适配器调用。拟合、探测、固定选择和审计成本单列，不声称自动更快或等真实CPU成本。

80项相关回归通过。独立审计重放27次最终选图，另用NumPy按年重算评分；核查训练/应用、验证/测试日期隔离，隐藏值不在算法源内，48份预测哈希与可见原值一致，逐日区间边界对齐。

前期诊断发现并修复点序列逐帧包装、维度顺序、区间起止标签、`0×NaN`污染非重叠区间等问题；V1—V5协议、日志和产物仍在工作目录，不纳入V6效果。测试计分后只修正天气导出客户端的Pandas日期索引类型及Windows审计路径归一化，不改科学选择或预测；冻结原源码与精确补丁说明均保留。

## 7. 天气格式交付及复现

`weather_handoff`含三遮挡情境×五方案，共15套2008—2013天气文件，每套2192日。方案为站点单源、ERA5原值、共同固定、自动seed11、随机seed11；seed11仅作预先固定的首种子样本，所有种子完整预测另存。

逐列回读`pcp/tem/slr/hmd/wnd`及索引通过：降水等于冻结产品到文件精度，其他气象变量保持原始值。文件仅用于替换相应天气输入的试验，不含`file.cio`、WGN、流域拓扑或完整SWAT工程，未运行SWAT原生模型。不覆盖完整原始观测。

证据目录：`output/robit_era5_fusion_20261027`。优先查看`effect_summary.json`、`test_metrics.json`、`independent_audit.json`、`weather_readback.json`、`predictions_frozen.json`、`controls_v6_frozen.json`及`runs_v6`。数据原件在`data/robit_era5_1990_2013`，运行源代码冻结在`source_frozen`。导出小修说明见`export_only_patch.json`。

复现脚本：`acquire_robit_era5.py`下载，`run_robit_era5_fusion.py`准备/搜索，`evaluate_robit_era5_fusion.py`依次controls→predict→score→weather，`audit_robit_era5_fusion.py`及`check_robit_era5_weather.py`独立复核。已交付结果不要在原目录重新prepare覆盖；若全量复现，应复制项目并另建输出位置，使用冻结环境版本与源码。

本轮到此冻结。若继续改选择机制，应另留新年份、站点或独立案例检验，不能反复用这六年测试追到优势。
