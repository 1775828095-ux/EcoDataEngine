### 2.1 `2021-2026空气质量日数据(1).xlsx`

- 时间：2021-01-01 至 2026-01-19，日尺度。

- 缺失：主要数值列约有 4,154 至 4,795 条缺失；首要污染物字段有 148,329 条空值或破折号。

## 4. 可组成的融合组合

### 组合 A：AirNow PM2.5 站点 + GEOS-CF PM2.5 背景场

- 同一物理量：是，但测量条件存在差异，需要在报告中保留。
- 时间重叠：是，2024-01-01 至 2024-01-02 的 8 个共同窗口。
- 空间重叠：是，洛杉矶附近。
- 可配准：是，站点 EPSG:4326；背景为经纬度网格。
- 可用方法：背景场 + 站点残差融合。
- 结论：当前唯一可以立即跑通的真实观测—真实背景场组合。
- 限制：站点太少且没有独立验证集，只能做工程流程演示，不能作为有说服力的算法精度实验。

### 组合 B：2019 国控站 PM2.5 + 2019 气温/气压/湿度站

- 同一物理量：否。气象只能作为辅助变量。
- 时间重叠：有 2019 年重叠。
- 空间重叠：全国范围有重叠，但站点并非一一对应。
- 可配准：理论可行，需要按经纬度与时间匹配，并确认时区、坐标格式和单位。
- 可用方法：PM2.5 空间插值；在共同样本和关系诊断通过后，可尝试气象 external drift/covariate。
- 结论：可做“观测 + 辅助变量”的研究准备，但不是“观测 + PM2.5 背景场”融合。

### 组合 C：2021–2024 城市小时空气质量 + 2017–2024 气象站

- 同一物理量：否。
- 时间重叠：2021 至 2024。
- 空间重叠：全国城市与气象站存在覆盖重叠。
- 可配准：需要城市中心/行政区与气象站的空间匹配；气温文件的坐标编码还需确认。
- 用途：城市尺度 PM2.5 与气象协变量建模。
- 风险：空气质量是城市聚合值，气象是站点值，空间代表性不同；不能假装是同站观测。

### 组合 D：真实水质观测 + 水环境空间数据

- 可用于水质空间化、格式转换和 WASP 数据准备。
- 不适用于 PM2.5 融合，不能跨物理领域直接合并。

## 5. 当前缺少的数据

针对中国 PM2.5 多源融合研究，当前本地资源仍缺：

1. 与 2019 国控站或 2021–2024 城市小时数据同期、同区域的网格 PM2.5 背景场，例如经确认的 CMAQ/CAMx/WRF-Chem 或再分析浓度产品。
2. 同期 AOD 或卫星 PM2.5 产品。本次没有发现可确认来源的 MODIS、Sentinel 或其他 AOD/HDF 数据。
3. 可核实的土地利用网格；现有 DEM 可作地形辅助，但不能代替土地利用。
4. 中国大规模数据的来源 manifest、时区说明、坐标定义和 QA/QC 说明。
5. 正式实验需要的独立验证站划分；不能把所有站同时用于拟合和评价。

## 6. 推荐的第一个实验方案

### 立即可做的工程验证

使用 `examples/engineering_case_air_quality/`：

1. GEOS-CF PM2.5 作为背景场。
2. AirNow 两站 PM2.5 作为观测约束。
3. 对齐时间、网格和 CRS。
4. 执行已有残差融合。
5. 输出融合场和质量报告。

这个方案可以证明平台的数据识别、配准、融合和输出链路能运行。由于没有独立验证站，结论只能是“流程跑通”，不能是“精度提高”。

### 推荐的正式算法研究

以 `国控.rar` 的站点级 2019 PM2.5 为观测基础，保留一部分站点作为独立验证集；再补充同年同区域的网格 PM2.5 背景场。气温、气压、湿度只在共同样本、空间覆盖和关系诊断满足条件时作为辅助变量。这个设计才能比较残差融合、Kriging、External Drift 等方法的 RMSE、MAE、bias 和空间稳定性。

在网格背景场尚未补齐前，可以先用现有 48 小时合成真值数据检查算法和数据泄漏防线，再用洛杉矶真实小案例检查工程兼容性。

## 7. 总结

- 当前已经具备大量真实空气质量观测数据，尤其是带经纬度的 2019 国控站数据。
- 当前已经具备一套小型、来源可追溯的真实观测 + 背景场 + 气象 + DEM 案例。
- 当前不具备中国大范围 PM2.5 观测对应的同期网格背景场，也没有可确认的 AOD 数据。
- 因此可以立即开展平台流程验证和合成真值算法实验，但中国区域的正式多源 PM2.5 融合研究仍需补充网格背景场与来源/QA 文档。
