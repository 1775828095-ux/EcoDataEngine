# 冻结协议：全量三画像初筛、开源变异选型与互补分辨率重建

本协议在查看NCEP实验成绩前建立。软件研究与工程验证，探索性选型；不是原生WRF验证或跨传感器确认性研究。

## 任务和信息权限

原始文件 `data/ncep_xarray/air_temperature.nc`，2013—2014年，每6小时一次，25×53网格。选择固定12×12区域（升序纬度索引6:18、经度15:27），每任务9个时刻。源H只保留第0和8时刻的12×12场（48小时间隔）；源C保留全部9个时刻，按原有面积权重算子降到6×6（6小时间隔）。输出第1—7时刻12×12；这些完整场在源H中删除，只作独立评价。

这是同一真实序列的受控降采样重建。原分辨率约2.5°，只能称相对高/低空间分辨率；合成面积观测支持是显式离散化假设，不能冒充源产品原生面积代表性或两个独立传感器。温度元数据degK标准化为K，数值不改。历史重建允许两端锚点，不称未来预测。

## 分组与选型规则

2013开发任务起始索引0、360、720、1080；2013验证1200、1340；2014测试1460、1820、2180、2540。每个episode为一个分析组，像元不当独立样本。原始输入与降采样算子SHA、时间和隐藏位置保存。

开发比较basic、ALNS/AlphaUCB、pymoo MixedVariableGA、随机对照；种子11、29、47。全部使用同一个完整画像初筛结果、2个初始方案、最多12次唯一实际图评价、48次提议、相同池及硬门。最大墙钟180秒。无初筛截断，旧screen_pool不再随机抽样。画像初筛预算不足应明确停止，不能退回随机。

选型主指标是实际执行画像分相对本任务池内最优画像分的regret；同时报告合法率、达到目标所需评价次数及真实内核调用/耗时。开发均值regret最小者进入验证；均值差不超过1e-9视为并列，优先适合分组修改且有原生算子反馈的ALNS，再pymoo、basic。验证不得劣于basic（regret差不超过1e-9），否则按开发次优顺序重新验证，保留失败，不更改阈值。此并列规则是工程取舍，不是性能优势证明。

选定后冻结策略与参数，测试种子11、29、47、71、101；测试保留选定策略、basic、随机和仅初筛方案。测试结果不得反馈选型或改权重。置信区间如计算，按episode分组，明确仅4组、不可宣称普适显著优势。

## 候选与评分

源H时间插值linear/nearest；源C空间nearest/bilinear/PCHIP/cubic，使用原边界适配器；融合包含主源为H或C、份额0.6/0.8的均值，以及基于显式粗观测算子的细节/残差转移，强度0/0.5/1。无额外后处理。结构数2×4×7=56，全部先经结构检查和三画像评分。

模型场景明确声明粗观测一致误差与可见稀疏锚点细节偏离，均为Kelvin尺度，acceptable=0、bad=2，等权；不是实测WRF敏感性。细节参考只由输入锚点插值得到，绝不读取隐藏完整场。学习或排序模型不替代三画像。执行后重测粗观测一致性和细节指标，未知保持未知。

原始数值误差RMSE、MAE、Bias只用于推荐冻结后的独立评价。按固定算法、均值融合、固定残差方案及池内事后最优比较。正式结论需区分“融合比单源好”“搜索比初始好”“搜索优于最强固定方案”。不以画像分提高替代RMSE收益。

## GitHub选型范围

审查N-Wouda/ALNS（MIT，7.0.0）、anyoptimization/pymoo（Apache-2.0，0.6.2）、facebookresearch/nevergrad（MIT）和coin-or/balans（Apache-2.0，MIP特定）。实际候选使用前两者的官方包；BALANS的MIP求解器适配不适合直接移植。STARFM/ESTARFM项目仅作融合背景，GPL、GPU及反射率假设不直接迁移到本次温度任务；新增线性残差投影不称STARFM复现。

实现/测试/结果中间失败全部保留，开发和验证不满足优势时如实记录。最终只称“本次固定任务、候选与预算下选定的实现”，不称全球最新最优算法，也不承诺有限预算找到真实效果全局最优。
