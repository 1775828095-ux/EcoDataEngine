# Robit站点＋ERA5降水：冻结实验协议

本轮为历史日降水缺失恢复，不是未来预测或空间降尺度。站点原始1990—2013年并无空值；人为隐藏已知值以获得独立的恢复评价标签。

第二来源选择ERA5 total precipitation，经Open-Meteo指定models=era5、nearest格点，覆盖站点11.6N/37.36E及1990—2013。官方资料与ERA5降水评价论文说明ERA5降水为预报累积字段，并不直接同化雨量计降水（美国雷达/雨量计复合产品的例外不适用于本区）。避免采用可能混入目标站点的CHIRPS等站点混合产品。

独立性边界：这是不同生产链的模式估计，不是独立地面真值；Robit原始日降水生成来源尚未核实，无法证明绝对统计独立。原始包与新下载文件、URL、参数和哈希均保留。ERA5格点值映射到站点仅作为点位代理估计，保留原格点坐标和空间支持记录，不将其改称站点实测。

主日界按当地UTC+3下载；站点原资料未声明日界，标为假设。另下载UTC日总量供预先声明的敏感性检查，不按测试效果挑日界。两个版本不当成两份独立降水源。

时间隔离：1990—1995仅拟合既有月均值、尺度和ERA5到站点的先验校正；1996—2001开发并选择固定图；2002—2007用于平台选图；2008—2013隐藏值仅在全部预测冻结后评价。拟合状态必须在应用期之前，且绑定被校正来源。未知属性/参数域不补造。

三类遮挡分别为随机单日、连续3日和连续14日，每年约20%（整块可略超）。位置只由固定随机种子决定，不能由降水大小决定；端点保留以允许历史插值。每个遮挡实验从应用期站点输入同时移除开发、验证和测试隐藏点。恢复算法上下文中没有这些点的值；状态和校正也不能用它们拟合。不同实验上下文及缓存独立。

被遮挡站点值只能作为对应阶段评价标签，不能既参与融合又当测试真值。其余未遮挡站点值可用于历史缺失恢复；允许缺口两侧可见观测，但不将这种实验称为实时预报。原可见站点值必须精确保留。

候选通过公共AutonomousField入口从全注册库按实际接口生成，不手写完整流程池。仅补点序列缺失回退和训练期状态适配；复用原时间恢复核、仿射拟合核和真实DAG执行器。输入接口和任务物理约束不因测试成绩放宽。资源初定每次180候选执行、40000提议、120秒；若仅基于开发期计时修正资源，另存修订并在最终测试前冻结。

评分采用逐年RMSE再等权平均，另报全隐藏点RMSE、MAE、Bias、湿日命中/虚警（阈值1mm/day）、强降水误差（训练期湿日90分位）、覆盖率和内核/墙钟成本。自然无真值位置不计误差；本数据人为遮挡之外无自然空值。单点纬经维度不能假装成空间场。

对照：①站点单源恢复；②ERA5单源原值及训练期校正；③开发期实际发现的最好固定配方；④同预算随机探索；⑤平台按验证效果自动选组合。原始完整站点只作离线标签与原始天气文件，不能作为“无误差融合基线”。所有完整候选真实执行，保留非法和失败图。

三搜索种子11/29/47重复同一遮挡参考，不扩增独立数据量；以测试年份为配对统计块，遮挡类型属重复测量。预先报告分遮挡结果、年份间异质性及描述性区间，不挑最好种子。

测试预测、图、参数先写入不可变指纹清单，再打开测试标签。负结果不删，不为了获得优势反复使用同一测试集调整方案。本实验只能验证降水恢复/准备效果，不能证明SWAT径流改善或全局最优。
