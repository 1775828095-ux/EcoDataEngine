# 公共入口机制修复与未使用数据实验协议

顺序固定：同分接受/科学状态去重 → 多源可见遮挡响应 → 联合破坏—修复 → 机制验收 → 冻结代码与实验配置 → 新数据对照。不得按测试成绩修改机制、种子或追加预算追优势。

工程修复复用PortraitMutation、既有Executor、日序列遮挡函数、DailyPortraitScoring的响应归一化、三画像状态评分以及ALNS/AlphaUCB。模型画像仍是明确的准备需求；原expected_error槽只作已声明的输入总量偏差代理，真实SWAT误差未知。默认数据/模型准备权重0.5/0.5、协同0沿用旧日恢复协议的实验先验，不称学习出的SWAT敏感性；有需求配置可覆盖并记录依据。

机制验收只使用旧Robit和合成定向数据。要求：同分增肥不接受；全域科学状态相同仅保留简洁代表，不能只比较验证位置；来源、校正状态、单位、区间和缺失掩码不同不得合并；质量门固定执行，不在科学节点中反复变异；完整数据再恢复跳过。多源探测必须从被遮挡根输入重新执行所有分支，不能复用未遮挡中间值；初始评分有真实差异，并证明需求改变可改变相应优先级。联合破坏要留下有实际移除节点的带洞部分图，修复后有完整可执行新连接。失败、探测、搜索、部署共享调用与服务墙钟账本，缓存无新增调用事件。验收不要求一定战胜某条指定路径。

新数据：公开GHCN-Daily雨量站Perth Airport（ASN00009021）、Broome Airport（ASN00003003）、Kalgoorlie-Boulder Airport（ASN00012038），2014—2024。三站在西澳，使用BOM通用9am当地日降水约定（UTC+8、该时段无夏令时），ERA5小时降水严格按对应24小时累计。GHCN PRCP/10为mm；-9999或负值、非空质量标记、部分时段或推定零值测量标记剔除。只接受空白/B/D/F/G/T等完整或trace标记；自然缺测不当作零，不计真值。原文件/元数据/请求/哈希保留。此前埃塞俄比亚新站点覆盖不足，按覆盖而非模型成绩排除；404站号错误保留诊断，不作为有效源。站点名单及QA规则在效果计算前确定。

分区：2014—2017只拟合；2018—2019开发/固定方法选择及可见响应探测；2020—2021验证选图；2022—2024最终测试。响应探测只在开发期原本可见值上额外遮挡。训练统计和ERA5校正仅用2014—2017有效配对。模型不能看到任何阶段隐藏站点值，ERA5作为不同生产链估计可见，不称独立地面真值。按日期与标记统计数据覆盖不构成查看隐藏测试效果；测试标签在预测冻结前禁止评分。

场景：连续3日与14日缺口，每年约20%，位置由固定种子决定，只遮原本有效值，首末边界保留；完整块略超目标允许，原始自然缺失另外标注。三搜索种子11/29/47，是重复测量，不是独立样本。主目标为每年隐藏日RMSE等权平均，最终跨站点、情境和种子等权汇总；附MAE、Bias、覆盖率及运行成本。统计以站点为聚类单位（三站），年份和种子不能扩增独立样本，区间仅作描述，不作强显著性主张。

搜索四组：①完整ALNS＋响应＋联合修复；②同父图策略、同邻域的均匀随机算子对照（画像修复开/关均匀选择，与ALNS拥有相同两类修复）；③ALNS去响应评分；④ALNS只保留局部编辑、去联合修复。所有组从历史最好图继续，按同一误差/简洁度/估计成本准则维护最好图。固定组从全部开发发现配方跨案例真实重放选择，另保留站点单源、ERA5单源及上轮固定配方转移对照。不得称发现配方数是完整合法空间。

统一总预算：每次最多180次新增注册算法调用，探测/搜索/失败/部署全部计入；最多120秒服务墙钟，最多40000提议，不增加上一轮资源上限。响应探测上限为总调用的1/3；消融节省的探测成本可用于搜索，不能暗中赠送探测预算。未完成或失败图无RMSE；缓存遍历不当新数值调用。共同数据整理和训练状态拟合的一次性成本另报，固定配方开发重放成本另报。正在执行的内核返回前不能保证硬超时，超时如实计，不补种子。配置和源码须在首次正式验证运行前封存。

开发按各站点/情境各一对完整ALNS/随机，种子704；固定配方选择只看开发标签。正式为3站×2情境×3种子×4搜索组，共72次，再对冻结固定/单源统一输出和测试。测试结果无论正负都交付；不将穷举补齐、已有测试再调、探测开销遗漏称为优势。不进行原生SWAT径流实验。新数据只有降水，不伪造其他天气变量。
