# 整日期验证与缓存短组合终点评价：修复及独立效果验收

2026-10-29启动，2026-10-30完成。

## 结论

两个公共机制已修复并经103项独立测试验证；30次真实公共入口调用通过（开发10、正式18、页面/API2）。逐候选审计证明：成功执行图中所有已缓存祖先均有独立终点评价记录，质量不合格的祖先仍为中间态。合计新增609条缓存前缀评价，未新增对应科学管线执行；正式6次随机结果中0次直接选择缓存短组合。

新2023年测试RMSE：随机0.12618816、不变异0.14081900、人工参考0.11872362。随机相对不变异收益+10.39%，相对人工参考-6.29%，相对高分单源+10.42%。正数为误差降低，负数为变差；机制验收不等于效果保证，负结果不删。

## 公共实现

1. current_input.raster_validation依据目标日期与主源的有效日期识别整日期恢复任务；自动采用完整日期/相邻观测日期块遮挡，按任务缺口的可见时间括号选择内部块；确认日期另取，两个端点保留。仅零散像元缺失、没有目标缺失日期时，原点遮挡仍适用。
2. 搜索、确认均从同一份掩蔽输入移除；同源副本同步遮挡，独立MODIS不移除。自然缺失不充当真值。少于4个有效可见日期则明确拒绝伪自验证，不退回零散点来冒充整日期验证。
3. field_mutation共用assess_terminal，对已经成功执行且缓存的祖先也独立检查目标日期/网格、完整输出、单位、物理范围及数值误差，写入同一evaluated/rank；不加任何特定算法组合。
4. 缓存前缀只读已执行结果，不再次调用科学算子或收益探测；total_new_calls=0，单列assessment_seconds和prefix_terminal_assessments，既不冒充新的管线执行，也不增加停滞计数。候选提议的剩余数值额度计算排除这些缓存评价。
5. 平台公共版本升为v6，页面结果标识含版本，避免更新机制后展示旧缓存。随机搜索、初始扫描、真实误差目标、硬门、节点同误差时的简洁性次序、既有停止参数及预算保持原样。未新增栅格收益学习器；原三画像栅格实测收益UNKNOWN的限制仍在，未伪称其已解决。

生产文件仅修改current_input.py、field_mutation.py、platform_search.py及search_page.py；没有改科学算法内核或人工参考图。页面与实验均调用同一公共实现，没有实验端额外修复或部署。

- 用通用数字变换以及真实注册的空间补缺→TV算子链证明：只提交较长图，已算短前缀仍自动获得独立终点评价；少节点且误差更好时能被选中，负值等不合格前缀不能越过质量门；无需再执行其数值管线。这是定向测试夹具，不是正式搜索的预设路线。

## 冻结的真实实验

- 2021年输入只作开发检查；2022年已见结果不作为新的盲测。不复跑2022选参数，也不声称其11%差距已被定量消除。
- 新下载同一爱荷华窗口的2023年Landsat8 C2L2T1与MOD09A1.061原生窗口184个，继续使用预先规定的产品QA与≥60%局部覆盖阈值；无效果筛选。高分48×48约25×33m、粗源9×8约500m、26个8日粗观测日期。10个合格高分日期，各隐藏5个作最终参考。
- 保留既有分散/连续隐藏规则、种子11/29/47。分散规则仍名alternating，但10日期取整后部分隐藏日期相邻，不宣称严格每隔一天；两种模式共享原数据，不能当两个独立地区。
- 随机与不变异共用同样输入、初始图、内部验证/确认、资源限额；8对开发/正式运行逐项核对通过。固定图是上一轮已封存的三条对照；没有给随机组传参考图、指定候选池/深度、验证设计覆盖或预算覆盖。
- 既有2015停滞策略保持冻结，作为工程容差迁移到新整日期验证；未宣称它是经新分布校准的统计置信界或全局最优证明。
- 全部图和产品以及页面复核结果封存，先做机制/真值访问审计，再读取外部隐藏值计算准确率。每个日期只在共同有限参考像元上算RMSE/MAE，再对日期、模式、所有种子等权平均，失败不删。

## 尚不能扩大结论的边界

本次连续缺失要恢复5个日期，而只剩5个可见日期：为保留两个端点和一个独立确认日期，内部最多能遮2个搜索日期。平台明确记录requested_block_dates=5、actual_search_block_dates=2、support_limited=true；不能据此声称长达5日期的验证已充分。整日期验证已替代原不匹配的点验证，但数据量仍限制对长缺口的覆盖，不能凭空产生真值。

这是单一区域、新一年及两个有关联掩码的小规模结果。未穷举，不宣称全局最优；未运行下游WRF/SWAT+。无论测试结果是否更好，都没有后验调规则、加预算或把人工路线塞入搜索。页面采用真实Streamlit控件/提交和真实后台；上传传输使用原始文件字节夹具，不包含浏览器原生文件对话框验收。
