# Robit＋ERA5已有变异机制接通与补跑协议

本轮按用户授权补齐上一轮遗漏的变异，不更换路线：三画像筛选 → 已有ALNS（AlphaUCB选择破坏/修复算子、HillClimbing接受） → 候选图真实执行 → 验证误差反馈 → 冻结最终选图和预测 → 测试。

平台公共入口新增明确的PortraitMutation模式。复用composition_optimizers的ALNS依赖与控制机制、Composition的三画像状态减风险评分、注册算法库和Executor。旧ALNS针对有限分类轴，本次只补开放DAG的变异适配，不以旧四十图或已发现591配方限制新搜索，不静默回退其他搜索器。变异覆盖算法替换、参数、节点增删、边重连及相邻单源步骤顺序；只在实际兼容时进入执行。

评分器复用已有注册属性和SWAT+降水准备偏好，数据来自可见输入，算法响应有解析或实际执行依据才填值，未知保留区间。画像先排序完整初始邻域、再指导修复候选排序；它不是伪造的降水误差预测。ALNS接受与最终选图用同一真实验证目标，画像同分按既有区间比较。真实SWAT敏感性仍未知，不捏造其优选权重。ALNS本身不保证全局最优。

复用20261027批次V6原数据、训练状态、遮挡及单源/开发固定/开放搜索/随机对照，输入哈希应一致。1990—1995仅拟合，1996—2001开发，2002—2007选图，2008—2013测试。三遮挡、种子11/29/47，主要预算同原每次180候选实际执行/40000提议/120秒；初始化和任何探测都计入预算。不把缓存命中当新增真实执行，也不把穷举补齐记为变异收益。

新增同适配器随机选择变异邻域对照，以及相同初始化无变异对照，区分初始评分与后续变异贡献。原有随机和固定也完整保留。主目标仍是按年等权隐藏日RMSE，再跨遮挡和种子平均；其他指标复用原评价。开发期仅调试实现与计时，不用测试改机制或选种子。所有新预测写入冻结哈希后才打开测试标签。

2008—2013结果上一轮已看过，故本轮为同数据机制补跑，不能称新的独立盲测。报告全部种子、负结果、耗时、内核调用及校正拟合成本。若无优势如实交付；验证最优不代表未知真值或测试全局最优。

验收：公共页面/API/文件客户端调用同一个变异服务；轨迹存在父子图、真实结构/参数变化、画像筛选依据、实际执行及接受拒绝记录；数据和需求变化能改变画像决策；无标签时从可见值自动遮挡并剔出算法输入，缺少可用验证明确报错；冻结预测回读与独立误差重算一致；天气输出保留原可见值和其他变量，不覆盖SWAT工程。

实现说明：初始化扫描真实注册库根节点邻域，逐项画像评分并按次序实际执行，均计预算；后续每轮按剩余提议/执行预算分配邻域探测，复用轮转调度避免未知端口算法独占预算。邻域是资源约束下探索，不声称逐轮完整枚举。画像修复使用保守分数，未知不抬分；另有随机修复保留探索。空邻域返回不可接受状态，不把未产生子图的操作当同分成功奖励。没有足够预算发生变异则明确标注，不冒充变异完成。

开发期机制修复：纯非负投影在输入已经非负时可解析证明恒等，筛掉这类编辑并保留日志；未处理源也作为可用零算法候选评价。ALNS沿用HillClimbing允许同分探索，但AlphaUCB接受同分子的奖励设为0（[新最好、改善当前、仅接受、拒绝]=[5,2,0,0]），避免大量数值恒等图给算子虚假成功信号。不是按最终测试收益修改奖励。V1—V5开发诊断全部保留；正式仅使用冻结版本。

计数口径澄清：公共请求的objective_limit=180约束不同图的评估请求，执行器允许逐节点合法缓存复用；图评估数不等于新增数值计算次数。另以每次Executor实际适配器调用增量，区分新增计算图、完全缓存图和零算法原始源图。cost_readback.json独立回读该增量；不把完全缓存图计作新增数值执行，不据此夸大变异计算优势。部署重放及xsdba拟合成本另列。无变异组只运行初始化，不人为补齐其预算。
