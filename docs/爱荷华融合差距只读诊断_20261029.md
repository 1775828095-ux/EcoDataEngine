# 爱荷华融合差距：源码和轨迹只读诊断（2026-10-29）

结论：本轮存在“短合法组合未作为终点充分评价”和“内部验证与实际任务错位”两个问题，同时三画像缺少本任务的数值收益响应。不能说人工完整参考已经参与数值排序并被打低分；现有记录没有它的独立内部验证误差。本次未修改生产代码，未重跑搜索或候选数值管线，未把人工路线加入平台。

## 1. 人工组合是否出现过

- 人工参考的实际定义为直接对两个原始源做visible_anchor_residual（residual_strength=1），再执行declared_range_projection。父源次序交换且fine_index相应交换视作同一科学路线，而非只比较节点ID。
- 6次正式搜索初始化都真实执行过直接锚点融合。它在遮挡输入上产生超出[-1,1]的值，measured报“Output outside declared application physical range”，所以记录为INTERMEDIATE_ONLY，没有合格终点误差。保留中间态并禁止越界结果作为最终产品是正确行为；不能因此把该科学算法整体说成不可用。
- 5次搜索的已存图中没有上述完整两节点链。连续缺失种子29存在等价完整链m4f281a24960e53dfe98ecfdcdb34497113e3b93f1ce17be32ca1cdda20faedcb。
- 进一步核对trace发现：这个完整链确实作为较长图的中间子图真实执行过一次（cache_hit=false、PASS），随后多次缓存复用。不能把它误说成仅存在图描述或从未执行。
- 但它没有作为独立sink出现在attempts的终点评价记录，也没有独立验证误差。GraphMutation.execute只给传入的sink计算measured；已执行祖先仅被retain_state缓存。因此“算过一个好用的前缀”不等于“把前缀单独列为可选答案并评分”。本次存在短合法终点覆盖缺口。
- 不能据现有文件判定：若单独评价该两节点链，它的内部误差会不会胜出。要回答该反事实需要另行数值执行，本次没有做。

## 2. 三画像是否能判断哪个恢复得准

- DAGResponse的实测响应分支仅支持lat=1、lon=1且至少30个时刻的逐日点序列。当前48×48栅格全部得到unsupported：“Visible-day response requires a daily point series with sufficient support”。这与另一个用于最终选择的栅格RMSE评价是两条不同逻辑，不能混淆。
- fallback没有伪造精度，而是保留data=[0,1]的未知区间；模型项主要依据当前应用契约唯一的eco_missing_fraction。对多数未执行的新图，恢复效果未知，所以每次运行的预筛得分区间总共只有1—2种，大量候选同分。
- 画像用于初始候选排序、portrait策略的提议优先级；最终rank实际是验证objective误差桶→节点数→稳定ID。节点数只在误差数值相同的情况下起作用，不是对复杂图的独立惩罚。
- 6次部署选中的图均等于内部validation_best，部署没有因失败换成较差图。因而没有证据表明是“排序代码把验证最优丢掉”，也不能说已验证有效的画像收益评分被故意覆盖。本任务的画像精度响应本就未适配，最终选优依赖内部RMSE。

证据：src/ecodata/algorithms/dag_response.py构造函数与score；field_mutation.py的matching/rank/propose；各run的response_scoring.json。

## 3. 验证为什么不能代表最终任务

源码current_input.raster_validation在每个仍可见日期内随机遮挡约20%的有限像元，再交替分给搜索和确认。该日仍保留很多邻近像元，且同一像元保留至少一个时间观测。6次运行没有任何整幅日期在内部输入中被完全遮挡。

实际外部测试则从输入删除3个完整Landsat日期，要求恢复当日整幅场。连续缺失测试的目标日期为7月9日、9月11日、9月27日；内部评分日期却是6月7日、6月23日、10月20日、10月29日。内部验证没有直接检验这段长时间缺口。

| 缺失模式 | 最终图内部验证均值 | 内部确认均值 | 最终图外部测试均值 | 人工参考外部测试 |
| --- | ---: | ---: | ---: | ---: |
| 交替日期 | 0.04166430 | 0.03812186 | 0.07544939 | 0.07592201 |
| 连续日期 | 0.04377084 | 0.03908134 | 0.15768895 | 0.13406091 |

这几列不是同一批标签，不能把数值差直接叫作测试误差“增加了多少”；它们显示当前低验证误差不能保证整日期恢复好。内部确认虽未参与选择，仍采用同帧零散遮点，因此也不能独立确认整日期泛化。

具体反例：连续缺失种子29，最终内部验证0.04095010、内部确认0.03758241，实际测试0.19172137；同种子不变异测试0.12594063，人工参考0.13406091。内部验证改善并未转化为该次实际任务收益。

事实：两种缺失模式在内部验证上相近，连续缺失的外部误差明显较大。推断：同帧孔洞验证容易奖励空间补洞、平滑等对该验证有用的复杂处理，却不足以约束长时段缺失恢复。这与3—9节点的最终图及误差轨迹一致，但不能从一次小样本研究量化各原因对11.03%差距的因果贡献。

## 4. 11%不是所有情况都差

交替缺失的随机均值0.07544939略好于人工0.07592201；连续缺失随机0.15768895劣于人工0.13406091，整体差距主要来自后者。随机对不变异的6次配对仅3次更好，不能把平均改善写成稳定胜出。

6次均以NO_MATERIAL_VALIDATION_GAIN停止，评价停滞阈值为86次新数值执行；不是超时丢结果，也未穷举。停滞只能说明当前探索和验证目标下没有继续明显改善，不能证明最优。

## 5. 应优先处理的方向（研究建议，未实施）
