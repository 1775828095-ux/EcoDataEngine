# 当前输入自主重选与部署验收

日期：2026-10-29。结论：本轮已修复“换输入后仍直接套用旧冻结图”的正常处理链路，并完成真实输入、失败边界及保存结果独立重放验收。精度优势未在本轮评价。

## 问题与处理

第72章执行的是2016选图后冻结迁移到2018的回顾实验。细源观测由6期变成3期后，旧DINEOF图不再适用，执行器正确拒绝，但原冻结迁移入口不会重新选择。这不能当成平台已完成每批数据自主处理。

现在公共入口`process_current_input`根据当前输入重新建立可见观测遮挡、三画像筛选及随机变异搜索，算法、参数、节点与连接由平台决定，不接受人工指定整图。页面正常无外部标签模式及文件工具的`decision_policy=current_input`共用此入口。实际后端为random，不是ALNS。数据或目标改变后，页面旧结果失效，必须重新提交。

每条候选图真实执行；只有满足目标日期、目标网格和完整性要求的结果才进入数值选优。解决了验收中发现的“只恢复已有日期，内部误差低却不覆盖全部目标日期”的相关漏洞。没有降低DINEOF最少日期或观测要求，没有修改科学算法内核来使旧图通过。

搜索后，在完整当前输入上重新执行选中图，核对范围、非负等质量要求，保护原有可见观测。如果最高排名图不适用，按原内部验证排序自动检查后续图；没有可执行图则明确返回`NO_EXECUTABLE_CURRENT_GRAPH`，不交付伪造产品。调用和服务时间在同一账本中计入，预留部署资源，未另加隐藏搜索预算。

严格冻结迁移接口`execute_frozen_graph`继续保留，用于部署指定冻结图及实验对照；它明确拒绝current_input策略，避免混淆“重新决策”和“冻结迁移”。第72章原失败、产品、结论和冻结源码均保留。

## 平台自己的判断依据与数据隔离

当前栅格可见观测按固定可复现遮挡划分搜索集与独立确认集，两者互斥，均从搜索输入移除；相同来源的副本同步遮挡。天然缺失不作真值，独立背景保留。搜索集实际恢复误差用于现有公共评价，三画像与质量门沿用既有机制；确认集只报告，不参与排序或自动改选。最终产品重新使用完整可见输入，保护观测。

确认误差从遮挡输入的输出计算，在恢复原值之前评价，避免原值保护造成虚假的零误差。该误差反映内部遮挡恢复，不能冒充未知日期真实误差，更不能证明全局最优。真实验收的决策阶段禁止读取原实验development/validation/test_labels文件。

## 适用边界与证据

本次验收对象是已声明变量、来源角色和目标的连续变量时空栅格重建；没有宣称新增了任意文件关系识别、任意任务自动推导或所有语义类型的通用评价。观测不足、质量不合格或资源耗尽仍可能无结果，平台会明确报告原因。原重复节点和跨数据泛化效果问题不因本轮修复自动解决。

未重跑第72章正式效果对照；`scientific_advantage=NOT_EVALUATED`。本轮证明自主重选和部署闭环恢复，不证明精度优于固定方案。
