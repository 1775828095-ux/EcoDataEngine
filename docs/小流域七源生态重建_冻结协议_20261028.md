# 小流域七源生态重建：数据与实验协议

研究区为黄山附近HydroBASINS出口4120774820的完整上游集水区，6个第12级子区，共1056.6平方公里。不能把204.2平方公里的出口局部子区误当完整集水区。所有边界、公开下载请求、版本、原生裁剪和校验保留。

共同年份2013—2017。Landsat-8 Collection2 L2 T1的30m红光/近红外及像元QA，CLCD v1.0.2的30m分类，NASADEM约30m高程及原生米制网格坡度，Terra MOD15A2H V061的500m LAI及QC，Terra MOD17A3HGF V061的500m年度NPP及gap-fill百分比，Peng等中国约1km逐月降水/气温。MODIS重复重处理版本按产品/时段/瓦片取最新；不重复计算同一观测。

公共数据接入模块按产品定义执行质量筛选、单位换算和语义准备：Landsat逐年5—10月选12景低场景云量T1、仍单独应用像元云/影/雪/填充值/饱和筛选，至少两次有效观测取NDVI中位数。FVC为像元二分代理，端元仅从2013—2014有效NDVI的5%/95%分位估计，固定用于后续年份，不是独立地面植被覆盖真值。DEM先在30m米制网格计算坡度再汇总；土地覆盖变成类别面积比例，不对类别代码取平均；NPP保留密度单位而非误称总碳量；降水原始0.1mm和气温0.1摄氏度按元数据换算，5—10月降水求和、气温按月天数加权。LAI取同期合格8日观测均值；NPP为全年度辅助变量，保留这一时段差异，不声称预测未来。

目标分析网格沿用气候产品原生1/120度中心，称约1km网格，不把插值网格说成新信息分辨率。原生FVC、DEM、坡度与原始类别/QA仍保留。公共接入规则只表达物理和测量契约，不规定任何胜出重建路线。

实际问题：恢复遮挡的区域FVC产品，检验辅助变量与处理图组合是否改善真实数值误差，不以网格覆盖分数替代精度。候选库通过真实接口发现；新增通用栅格缺口适配器复用SciPy，辅助估计复用已有feature_forest数值内核，特征子集由实际带单位的协变量自动提议，不预设“植被组/地形组”等固定优胜搭配。使用同一公共PortraitMutation随机变异入口，平台自己决定节点、参数、特征子集、连接和最终图。不得提供手写完整候选流程池或手工挑最终方案。

2013—2014只拟合端元、训练目标与预测器；2015开发与选择固定对照；2016验证选图；2017测试。算法输入只含被遮挡的2015—2017 FVC、2013—2014拟合的FVC气候态、独立标单位的七类协变量，以及仅训练期非空的training_target。原始未遮挡Landsat反射率/完整FVC参考不进入搜索端口。辅助变量允许自己的真实缺测，预测器仅用训练期拟合中位数填补，不把原始缺测改成观测。

按共同有效像元与流域边界、仅依据几何与质量确定3个互不重叠空间块。优先8×8格且全部在流域、五年份参考均有效；若几何上不够3块，改用6×6并在任何效果计算前记入协议。不得按恢复误差挑位置。每个案例在2015—2017移除相同空间块的FVC输入，原始自然缺失另记；参考只计被遮原本有效值。训练期目标不受测试遮挡影响。区域、种子是重复测量；单流域单测试年不支持广泛泛化或强显著性主张。

正式随机变异/不变异各3案例×3种子11、29、47，配对初始化规则相同。不变异只完成同一初始化，不能强迫消耗无意义调用以做出同耗时。各搜索统一上限180新增注册算法调用、40000提议、120秒软服务墙钟，在算子边界检查；已经执行的内核可能超过120秒，超时如实计且不补换种子。失败、探测、部署均计入；缓存无新增调用。逐日点序列响应探测不适用于栅格时必须标UNKNOWN，不能把栅格伪装成点序列；保留真实三画像状态/契约筛选与隔离验证误差反馈。没有GOLEM或ALNS替代随机变异。

开发种子704分别运行随机/不变异。固定对照从全部开发已发现配方跨案例真实重放选择，另保留先验气候态、最近邻/线性/三次单方法、全部实际协变量的单森林。固定图只属于对照，不进入随机搜索初始化偏好。候选并非有限整图池，不穷举认证全局最优。

主指标为相同被遮空间块上的FVC RMSE（0—1比例），辅以MAE、Bias、边缘误差、覆盖率、物理合法率、科学节点/逐源结构与完整计算成本。预测与选图先冻结哈希再开测试评分；逐案例/种子、失败、负结果全部保留。对共同固定及不变异分别比较，不能把输入准备成功、组合更复杂或验证误差下降当成测试优势。

测试前补充对照：从每次随机搜索已经真实执行的合格图中，以2016验证误差选出最好的零/单科学节点图，单独封存预测，再统一评价2017。它不增加搜索预算、不进入主搜索初始化、不改变主选图；部署重放成本另记。只有随机最终图对该参照也有改善，才有更直接的多节点组合收益证据，避免把RF特征子集选优叫作多算法协同。

来源依赖：CLCD与FVC都使用Landsat信息，NPP与LAI共享MODIS生产链；本实验是受控的产品缺口恢复，不是独立传感器真值验证、云下绝对FVC精度验证，也不运行生态/水文原生模型。不按2017测试成绩改机制或追加预算。
