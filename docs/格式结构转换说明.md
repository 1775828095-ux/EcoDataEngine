# 第 2 项：格式与数据结构转换

入口：左侧“格式与数据结构转换”。本页调用同一个 `SequentialPipeline`；结构变化由 `StructureConverter` 记录，读写使用 xarray、h5py、Rasterio/GDAL、PyShp、pandas。旧算法入口和实验结果保留。

## 当前转换范围

| 输入 | 可执行路径 | 需要明确的信息 |
|---|---|---|
| CSV、TSV、Excel、JSON records、Parquet | 仅格式转换；表格转规则网格；表格转点矢量 | 结构变化时选择 x/y、数值列及可选时间列；空间输出确认 CRS |
| NetCDF、NetCDF-compatible HDF5 | 转表格；转 GeoTIFF；网格中心点；整数分类区域多边形 | 多维数组导出 GeoTIFF/分类多边形时显式选择二维切片 |
| 原生 HDF5 | 显式 dataset 映射后转 NetCDF、GeoTIFF、表格/点矢量 | 二维数值 dataset、一维 x/y dataset、匹配的轴长度和 CRS |
| GeoTIFF | 转 NetCDF/HDF5-NetCDF、表格、点矢量；整数分类转区域多边形 | 已有 CRS、无旋转仿射变换，多波段需要选择 band 切片 |
| GeoJSON、Shapefile ZIP | 矢量格式互转；带几何字符串的表格；矢量栅格化 | 属性字段、栅格范围、行列数、重叠规则和像元命中规则 |

只改变文件格式不需要设置时间/空间分辨率。表格 → 网格按坐标建立结构，不等于插值；矢量 → 栅格是按几何覆盖赋值，不等于模型模拟。

## 关键规则

- CSV 无字段类型声明，读取时先保留文字，避免 station_id 的前导零丢失；参与空间操作的坐标和数值列再显式转成数值。
- 同一时间与坐标重复时拒绝转换，不能隐式取最后一行。未覆盖的网格位置保留为缺失值，不自动插补。
- 原生 HDF5 处理 `_FillValue`、`scale_factor`、`add_offset` 等可解码 CF 属性；不凭 dataset 名猜测坐标、变量和单位。
- 单位冲突时拒绝只修改标签。CRS 已知时不允许填写另一 CRS 来冒充重投影。
- GeoTIFF 保存选中的二维变量，使用 float64 与 NaN nodata；其余字段不是波段。单位、坐标切片、转换历史写入标签及报告。
- GeoJSON 按 RFC 7946 输出 WGS84；已有投影坐标通过成熟库转到经纬度。原投影信息仍保留在报告。表格里的原坐标属性不自动改名或替换。
- 栅格化默认遇到重叠报错，也可明确选择先出现/后出现要素优先。默认像元命中采用库规则，可选择所有相交像元。明确范围外的几何会被裁剪，未覆盖部分为 nodata。
- 分类多边形化只接受 int32 范围内的整数分类值，不自动把连续浓度分箱。
- Shapefile 输出 ZIP 带 .shp/.shx/.dbf/.prj/.cpg 和元数据 JSON；不静默截断长字段、长文本或数值精度，遇到不能无损表达的数据提示改用 GeoJSON。
- JSON 报告保存来源 SHA256、原字段/坐标元数据、转换选项、历史及实际导出信息。重新读取带历史的格式继续追加历史。
- 参数/输入改变后必须重新执行，不继续提供上一次的下载文件。

CSV/TSV/JSON records 不能完整携带单位、CRS 和字段类型，须同时保留 JSON 报告并在再次导入时确认。Excel 导出带元数据工作表，Parquet 带 pandas 元数据；这两种表格重新导入仍按表格处理，不擅自还原成原网格。

## 明确边界

- HDF4、任意多维原生 HDF5、卫星 swath/曲线网格尚未覆盖；本轮原生 HDF5 为二维规则坐标映射。
- 旋转/倾斜 GeoTIFF 要先重投影；此入口不提供任意栅格目标 CRS 的重采样操作。
- Shapefile 输入限二维，输出限同一种 Point、LineString 或 Polygon。Z/M、多几何混合、复杂嵌套属性等会提示不兼容；不自动修复矢量拓扑。
- 缺失文字/混合字段不能无损通过当前 NetCDF 写入路径时拒绝，提示使用 Parquet 或明确缺失编码。
- GRIB 尚未接入。GeoTIFF、Shapefile、本轮原生 HDF5 使用新页面；原“数据处理”页仍用于原有插值/融合/QP 流程。
- 当前限制表格展开及栅格为 200 万单元，较大数据先裁剪/分组；不能把有限测试解释成支持所有格式产品。
