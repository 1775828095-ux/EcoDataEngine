# 支持格式与真实能力

| 格式 | 读取 | 写出 | 已验证结构转换 |
|---|---:|---:|---|
| CSV / TSV | 是 | 是 | 混合字段表格、表格与规则网格、点要素属性 |
| Excel | 是 | 是 | 表格；EcoData 元数据写入附加工作表 |
| Parquet | 是 | 是 | 表格；类型与 EcoData 元数据 |
| NetCDF | 是 | 是 | 多维数组、规则网格、CF 风格元数据 |
| HDF5 | 是 | 是 | NetCDF-compatible HDF5；原生 HDF5 需明确二维数值 dataset、x/y dataset 和 CRS |
| GeoTIFF | 是 | 是 | 二维规则栅格、nodata、CRS、仿射变换和所选字段 |
| GeoJSON | 是 | 是 | RFC 7946 二维几何、属性；投影数据写出时转换为 WGS84 |
| Shapefile ZIP | 是 | 是 | 一组二维 `.shp/.shx/.dbf/.prj`；字段名和 DBF 精度限制会明确报错 |

真实结构转换包括：表格→规则网格、表格→点、网格→像元中心点、矢量→栅格、整数分类栅格→多边形，以及上述容器的保真读写。不是简单改扩展名。

当前不支持：GRIB、HDF4、旋转/倾斜栅格直接处理、非规则曲线网格、三维矢量、任意 HDF 内部结构自动猜测。复杂文件需先明确映射或使用专用适配器。
