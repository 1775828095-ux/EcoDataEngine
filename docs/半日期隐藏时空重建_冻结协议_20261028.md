# 半日期隐藏时空重建协议

状态：实验前协议；尚无效果结论。

问题：保留约一半 Landsat 清晰影像日期和独立 MODIS 粗分辨率序列，由平台自动组合与随机变异，恢复被隐藏日期的高分辨率 NDVI。主目标不是网格对齐，也不把粗图放大视为增加真实细节。

数据：同一黄山小流域，2013—2017 年 Landsat8 C2L2 T1 红光/近红外与像元 QA；MOD09Q1 V061 Terra 原生标称250m、8天反射率与双质量层。Landsat 原生30m；仅最近邻投影到0.0003度网格，东西约29m、南北约33m，不能称精确30m方格。MODIS仅按近似原生间距0.0024度投影，平台处理时才升至细网格。NDVI两传感器光谱响应和复合期内观测日有差异，不施加虚假的精确面积均值守恒。MODIS来源 https://doi.org/10.5067/MODIS/MOD09Q1.061 。

样本：三个48×48像元空间分离区域；位置只依据流域几何及2013—2014年两传感器实际清晰观测覆盖，排除仅有名义覆盖但粗源没有实际观测的区域。只接受参考影像中QA有效且位于流域内的像元，单日期至少30%像元清晰（边界裁切前至少约692个原生尺度参考像元）；自然云缺失不充当真值。完整收集全年影像，保留满足QA支持的日期，不按算法误差挑日期。原4—11月/70%清晰的摄入检查在区域0的2016年仅找到两个日期，不足以进行半日期隐藏；此修订在任何数值效果实验前作出，旧协议与失败记录保留。

遮挡：每年符合QA日期中隐藏 floor(n/2) 张，保留两端锚点。交错隐藏与连续中段隐藏各一类，共6案例。日期数量为奇数时比例稍小于50%，逐例列实际比例。被隐藏整期的所有像元及派生产品均不进入搜索；不输入年度FVC、CLCD或NPP。可用未来可见锚点，因为目标是历史重建，不是预报。

隔离（最终v3）：2013—2014仅确定区域与质量支持；2015开发；2016搜索验证；2018最终测试。三个阶段生成各自独立输入，验证阶段不访问2018可见锚点。最终图冻结后由平台同一DAG执行器在2018可见输入上部署，不接收测试标签、不重新选图。当前不训练算法排序模型，不把处理节点的数值插值称为元学习。

历史使用边界：同流域2017年部分Landsat数据曾参与上一轮年度FVC实验。本轮按新任务重新隔离日期NDVI标签，属于回顾性任务评价，不能称这批数据从未被研究者接触过的全新盲测。

元数据修订v3：2017诊断已打开，保留随机变异RMSE0.06229850、不变异0.06110817的负结果，不因成绩调权重。粗源插值因输入缺少data_kind='continuous'被拦住，这是客户端元数据遗漏；修正已知NDVI连续属性后完整重跑开发与验证。最终留出年改为新获取的2018，不复用2017检验修复后的优势；区域仍由同一2013—2014数据确定。正式验证前对所有固定对照进行2015真实执行验收，粗源插值和开发固定方案必须可执行。

公共接口同时修复类型契约同步：请求已明确确认continuous/categorical而文件尚未标注data_kind时，将此已确认声明传递给数值后端并记录依据；文件明确声明的类别与请求冲突时阻止执行。不是从未知数据猜类型，也不覆盖已有冲突。范围投影作为数学上幂等的合法操作可部署到无违例新输入，搜索在当前输入上仍跳过恒等投影。

部署边界修订v3.1（2018测试误差未打开）：新年输入中某些补缺父节点已经完整，原兼容性判断把数学上的恒等补缺误报为不可执行。公共栅格补缺及时间插值允许对已完整输入原样处理；搜索候选生成仍依据实际状态跳过恒等节点。保留68份旧部署产品及4项失败，其中3项是此接口问题，1项是原始残差越界；全部在diagnostic_runtime_contract目录，未读取2018测试误差。用同一批输入、种子与预算重跑开发、验证后再部署。

搜索：平台公共 PortraitMutation 服务，显式 mutation_control=random；复用既有初始化、合法性、状态去重、真实执行和变异。无手写完整候选图池、无指定胜出流程、无最大图深度。只补公共整期栅格时间插值节点和可见锚点残差传递节点，明确这不是STARFM。原有三画像适用性评分保留，栅格响应暂不支持的部分标UNKNOWN；实际验证误差用于选优。

数值修订v2（正式验证/测试前）：首版开发发现同一数组由float32转成float64即可使RMSE减少约1e-9，已保留全部首版开发图及未完成的固定重放到diagnostic_float32目录。所有误差差分、平方和梯度统一float64；搜索同分尺度采用 eps64×有限参考像元数×max(1,参考绝对尺度)，仅作为累计舍入上界，之后比较节点数和成本。完整有限网格已与目标相同时，网格中心精确插值适配器不再重复原位插值；真正改变网格的IDW、MetPy、Kriging等仍开放。复用原冻结数据、原种子和原预算重跑开发，之后才能启动正式验证。该修订不改变科学内核，不接触测试误差。

统一资源上限：每次180次真实适配器调用、40000次提议、300秒软墙钟；缓存不记新调用，失败计成本，在途数值内核可能超时后才返回。开发种子704；正式11、29、47；6案例×两机制×3种子=36次正式运行。不变异对照共用同种子初始化。失败种子保留，不补换预算追优势。

对照：高分影像时间线性/最近邻插值；仅MODIS粗图时间插值及空间双线性；固定可见锚点残差传递；残差传递加显式NDVI范围投影；2015开发图中跨案例真实重放选出的最强固定图；相同初始化但不变异。原始残差的物理越界失败保留，投影依据NDVI定义[-1,1]而非测试误差；投影在已合法的新输入上可作为恒等操作部署，搜索仍跳过这种恒等节点。固定图必须在冻结前选定，不按2018误差挑“最强固定”。开发图集合是发现集合，不是穷举空间。

评价：主指标为隐藏日期等权RMSE，再按案例等权；同时报告全像元RMSE、MAE、Bias、梯度误差、固定参考像元覆盖率、超范围率、计算成本、每种子轨迹。像元支持由参考QA预先确定，缺少对应预测必须失败，不能只评分成功子集。测试前冻结图与预测哈希，然后一次性打开测试参考并比较。

附加类型：在不改选图的条件下按可见粗源时序变化分层，单列变化较快的隐藏日期，观察突变恢复能力；这是次要分析，不以测试结果选择困难样本或新增调参。单源对照直接反映粗源是否有帮助。

声明边界：一个流域三个相依区域、一年测试；像元或种子不当作大量独立流域。不能保证组合获胜、不能声称全局最优、不能从NDVI重建推断SWAT+/WRF收益。若时间插值或固定算法胜出照实交付。
