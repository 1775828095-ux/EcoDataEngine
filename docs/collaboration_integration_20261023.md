# 多阶段算法协作接入与验收

本轮是公共接口和数值执行机制补齐，不是新环境数据优越性实验。没有下载数据、安装依赖、改动原始数据或重训生产排序模型。

## 实际接通的组合

|协作|可替换环节|已验收|
|---|---|---|
|各来源分别校准→逆方差融合|每个来源可跳过或使用站点仿射校准|两个来源的4种分支组合均实际执行|
|各来源重网格→融合|最近邻/双线性分别选择|2×2种分支选择实际执行|
|各来源重网格→可选校准→融合|校准独立作用于指定来源|含五个科学节点的完整图执行/回读|
|融合→残差估计→背景相加|GP、普通克里金、MetPy线性|三种估计器分别真实调用；线性只验收完整空间支持情形|
|融合→非负投影|保留原融合与投影组合|真实调用既有投影内核并回读|

既有空间重建→QP不改科学内核；后处理绑定现可接多源结果。没有独立验收新多源QP科学应用，不把粗观测一致性当物理质量守恒。

## 实现与数据流

`collaboration.py`由公共`bind_registry`调用，不在实验脚本或页面另写规则。
来源端口经过可选校准产生新阶段kind，再交给下游科学节点；跳过路径仅传递原产物，不计科学算法。
来源重网格继续使用既有Registry算法。校准复用`quality_aware.fit_affine_source`，新增`bias.station_affine`只是已有数值内核的公开包装。
新增校准不会自动触发：需要明确allow_training、合法训练站、单一匹配时刻/物理变量/单位和完整背景覆盖；无资源时不提供该分支。
本轮校准拟合当前输入小时的可用训练站，不是未来预测，也不是持久历史状态训练API。

残差估计与背景相加现在是分离的真实节点。前者从实际父背景采样，计算训练站观测减背景，再调用原GP/克里金/MetPy内核；后者消费这个修正场和同一个背景。
生成阶段要求两分支使用同一背景子图，运行阶段再次核对背景内容指纹。错配不能靠schema相同蒙混通过。
不允许对已修正场或纯站点插值再套相同残差流程作为已审核背景。缺少空间覆盖时不偷偷删评价点或填真值。

校准对已有输入标准差仅按仿射斜率绝对值缩放；不包含校准参数误差，不称完整校准不确定性。未提供不确定性的来源不能进入逆方差融合。
没有把GP条件方差自动当成新融合权重。需要重新验证相关性和方差校准后才能做这种扩展。

## 评分、冻结池与页面

所有新科学阶段均按实际注册ID计入steps；三表画像、能力验收、既有评分和质量门继续参与。未添加无依据的组合收益或精度保证。
默认科学步数仍为3；多来源支路每个实际算法都计数，需要时可明确设置max_steps至6。本轮五节点验收显式设置5，没有隐藏节点以凑短流程。
冻结池按实际任务适配器判断空间包装别名，不把多源分支的原生重网格误换为不可用栅格包装。
结构直通节点可以保留，未请求的校准/估计器必须移除。适配器实现文件进入候选指纹。
背景所有权筛选不能掩盖上游枚举截断，冻结池达到生成上限时仍拒绝宣称完整。
无参考只推荐、不执行或拟合；正式数值评价仍由单独评价器完成。页面处理函数与工具包都消费公共submit_search，未新增客户端规则。

## 验收证据

- `output/collaboration_release2.xml`：77项通过。
- `output/collaboration_guard.xml`：33项通过，覆盖最终截断保护、全部协作、GP和旧冻结池机制；与前一组有重叠。
- `output/collaboration_clients.xml`：页面处理函数实际执行对照与截断负例2项通过。
- 三份XML按classname/name去重共80项通过，不累计为112项。
- `output/collaboration_independent_audit.json`：独立读取32份公共入口组合产品，SHA、有限性、单位和适用时的背景+残差算式全部通过。
- 独立核验程序：`tools/audit_collaboration_integration.py`，输入具体验收目录，输出审计JSON。

中间失败产物保留：空间别名错误、可变端口类型闭包、约束丢失标量时间坐标及测试夹具错误已分别修复或纠正，没有放宽质量门。依赖库弃用警告仍保留。

## 明确边界

80项测试与32份产品使用合成输入调用真实内核，是运行可用性证据；不是32个独立环境样本，不证明协作提高真实精度。
未接通所有任意算法串联、含缺失场的通用传播、所有非恒定辅助变量重网格、所有时间/垂直/地形算法的跨家族组合，专用station_covariates Profile仍保留原限制。
现有阶段画像可以追踪实际中间产物，但未实现执行中自动重新规划。
新增候选不会自动获得旧学习模型支持，旧冻结池也不自动扩大；后续实验需冻结新池并重新积累开发证据。
