# 新区域独立时空重建实验（2026-10-29）

## 结论

平台在这批新区域数据上完成了30次公共入口调用（开发10次、正式18次、页面与API复核2次），全部输出通过质量检查。没有改动生产源码、候选池、评分权重或默认预算，没有实验脚本追加部署。

随机变异测试RMSE为0.11656917；相对不变异误差变化收益+6.80%，相对预封存人工参考-11.03%，相对单源时间插值+10.22%。正数表示误差降低，负数表示变差。不能把运行通过等同于搜索有优势。

## 新数据和隔离

- 爱荷华州农田窗口，中心41.74°N、91.82°W。不是昨天的黄山数据；本次没有声称该矩形是已核实的小流域。
- 数据均重新下载：Landsat8 C2 L2 T1原生30m红光/近红外与QA；MOD09A1.061 Terra原生500m、8日合成红光/近红外与QA。356个原生窗口全部下载成功，有原始URL、元数据、SHA256和下载回执。
- 既有科学读取函数执行QA与NDVI定义转换，并分别以接近原空间尺度的网格保存；高低分辨率输入没有预先统一到高分辨率，也没有在准备脚本中完成融合。高分辨率目标网格48×48、0.0003°，当地约25×33m；粗输入9×8，约500m。
- Landsat QA位0—5清零且无饱和；MODIS使用官方500m QC位2—5/6—9的红光近红外最高质量位及云/阴影/卷云/雪/邻云状态，不能照搬250m QC位。只保留局部有效像元覆盖≥60%的Landsat日期；不依据算法效果选日期。
- 2021开发年15个合格日期，分别隐藏7个；2022最终评价7个合格日期，分别隐藏3个（42.9%，奇数取整）。交替隐藏与连续隐藏共享同一原始数据，不能当成两个独立区域。
- 本轮不训练新模型。既有停止条件来自2015年开发数据，原样迁移；2021只做链路检查。2022隐藏值从平台输入中完全移除，外部标签仅在所有输出封存后用于比较。自然缺失不作真值。
- 平台内部会从当前可见观测再划分自验证/确认遮挡，用于自主评价；与外部隐藏日期不是同一批标签。

## 预期路线与平台决策

预先封存的假设为：粗分辨率时序提供时间变化，可见高分辨率影像提供空间残差细节，再通过既有物理范围节点约束输出。它可能优于单源插值，尤其连续缺失时；这是假设，不是指定正确答案。

该参考图仅用于独立固定对照。平台随机变异与不变异调用均禁止读取参考文件和外部标签，只接收可见输入、同变量重建目标、网格日期和NDVI质量契约；没有预设算法图、节点顺序、深度或局部候选池。随机变异和早停均由平台公共入口完成；不变异组保留相同初始化与数值评价，只关闭后续变异。

## 运行验收与边界

所有输出均检查目标网格日期、有限值覆盖、NDVI[-1,1]、原始有效观测保持；失败候选保留账本。生产源码与原始输入哈希复核通过；外部真值参与决策0次，实验脚本补跑部署0次。页面真实控件和提交事件与API通过一致性检查，并与正式种子11结果一致；文件上传传输使用AppTest原始字节夹具，后台未模拟，不包含浏览器原生文件选择框验收。

这是一个新区域、一个最终年份、两种关联缺失模式和3个随机种子的小规模检验。没有穷举，不宣称全局最优；没有运行SWAT+/WRF，不宣称下游模型收益；既有停止规则是否适合更多区域仍待检验。负结果与正结果按同一标准保留，不为本批结果重调评分或预算。
