# 扩展空间重建与可靠选优迭代协议

本轮由用户授权实际迭代。目标是同时提升可靠推荐覆盖与真实选择质量，不关闭弃权，不为了覆盖率放宽已有支持域，不以测试集调参。

## 数据、候选与隔离

数据来自xarray官方示例库air_temperature.nc（原NCEP/NMC sigma=.995气温再分析），2013—2014年北美25×53网格；源地址与SHA见output/spatial_next_20261023/protocol.json。不是ERA5 2m气温或站点真值。取两个不相交24×24经度域，先面积平均退化2/3倍再重建；评价统一内部区域面积加权RMSE。目标参考只由评价器读取。

七种基础重建：最近邻、双线性、PCHIP、三次、已有IDW、MetPy linear、普通克里金；每种可接已有QP一致性校正，共14图。后三种通过平台公共适配器把粗均值解释为中心值代理，明确近似与边界填充，不新增插值科学内核、不伪造点观测。其他缺地形/训练/权重或输出含义不合的库算法不为凑数量加入。硬一致性情景只允许七QP图。

首次训练用2013每月1/15日00时，24时间×两域×两倍率=96任务。校准用2014年1/2月1日00时，共8任务。开发验证用2014年3—6月1日00时，共16任务，允许用于诊断和迭代选择。最终审计用2014年7—12月1日00时，共24任务/6日期组，所有模型、策略、固定基线和无参考推荐封存后只打开一次。不以审计失败反馈修改本轮策略重报。

## 比较与自适应迭代

所有图走submit_search公共入口真实执行，每任务完整覆盖14图且失败保留；迭代共享未变图的已执行产品，不能当作新增执行。固定算法逐项留存；开发期选出的最强固定图按区域/倍率/硬约束冻结作为强对照；另保留成本、三表规则、均匀随机10种子。

首轮仅增数据与候选，沿用原指标预测及逐特征支持门。若验证不足，由diagnose_spatial_next读取支持匹配及越界原因；预定增强训练为2013每月1/8/15/22日00/12时，共384任务，不使用验证/审计标签训练。若覆盖够而选择质量仍不足，优先复用已有但原主排序未使用的任务内排序头，或学习相对开发固定参考的收益，新增策略必须在公共模块生效并验证契约。新模型/代码/结果另存版本，不覆盖旧负例。

在首次验证输出前冻结的工程目标：每场景学习覆盖≥80%，整体RMSE相对规则与随机各降低≥5%，相对开发最强固定图不劣于2%。这是可用性与对照表现门，不等于特征自适应创新证明；还需报告相对强固定图的实际收益、选图差异、负收益率和池内最优差距。若只有固定图等效表现，必须明说额外自适应价值尚未证明。不能保证实验必然得到科学正结果。

评价报告按日期组汇总，不把图数/像素/随机种子当独立样本。开发验证多轮属于探索性选择，最终审计仅六日期组，不能夸为广泛泛化或统计显著。保留所有轮次、失败、越界诊断、训练/校准日期、产品回读与代码指纹。
