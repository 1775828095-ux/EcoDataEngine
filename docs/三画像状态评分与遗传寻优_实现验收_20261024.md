# 三画像状态评分与遗传寻优：实现与验收

日期：2026-10-24。本轮为平台机制实现及有界验收，不是正式科学效果实验。老师对话已阅读；先前正式实验和负结果保留。

## 1. 已接入的决策链

公共 `submit_search(..., mode="Profile")` 在显式提供 `portrait_policy` 后，复用原有模型契约、属性注册表、类型图生成、硬过滤、执行器与参数校准。页面处理函数和文件入口使用同一路径。未指定新策略的旧请求保持原行为；验收用合成场景没有发布为生产默认。

数据画像测量当前可见数据的问题；算法画像提供有证据的状态转移；模型场景规定问题尺度与偏好。每项评分保存三者的依据和未知项，不另用黑盒排序替代三表。

问题风险为 `r(q)=clip((q-acceptable)/(bad-acceptable),0,1)`；组合得分为 `Σ w_j θ_j [r_j(输入)-r_j(组合输出)]`。场景重要性归一化为权重，既有校准机制调整软乘数 θ；硬约束不参与权衡。声明成本如启用则单独按 `c/(1+c)` 计入，独立图节点只计一次。

当前消费者包括缺失比例、负值比例、源范围超出、峰值损失、粗糙度、目标网格不匹配、粗尺度一致误差和有依据的可用观测偏差。它们不是通用物理正确性判据：负值必须由具体变量场景决定意义；粗糙度不等于噪声；源域峰值不同于目标域峰值；观测偏差可能是样本内指标。粗糙度使用原域归一坐标，裁剪域峰值不可比时保留未知。

## 2. 组合如何更新状态与学习

按图拓扑逐节点更新状态。已审查的插值/投影性质可解析传递；不具有保证的平滑、峰值等副作用不填常数。执行时记录真实前后状态、模式、参数和输入指纹。

`learn_portrait_memory` 只读取完整、真实执行的开发记录，按独立组拟合算法响应与整链响应；留出组不训练，最终测试记录拒绝进入训练。内容指纹阻止同一数据改名成为新独立案例。失效记录保留，超出支持范围或证据不足维持未知。

学习对象是可解释的指标变化及特征变化，不是另一套算法排名。单父输入的可测节点可形成局部响应，多输入效果不会强行拆成独立贡献。状态依次传播后，整链案例只能补未知项，不能覆盖解析保证。响应区间是已观察包络，不是未来置信区间。

未知项计入保守效用区间，并标记推荐是否仍未解决；例如已知输入风险 r、输出未知时，效用区间为 `[r-1,r]`。公共软参数校准也使用相同区间，不偷偷改成点估计。新属性仍须注册测量/消费逻辑及依据；没有自动发现物理属性或自动生成测量器。

## 3. 模型画像如何处理困难

七个既有模型模板复用已审查输入契约，科学敏感性默认未知。模型文档/本地源代码检查仅提取有界的字面线索（含结构化 JSON 与 WRF Registry），标记需要审查，不自动获得科学权重，也不把代码字段当作敏感性证据。

场景策略按版本发布：模型、变量、角色、任务、阈值、重要性、依据和可选跨变量关系必须明确。与旧模型契约快照绑定。已支持显式变量求和约束及单位/维度检查，但不是完整多变量动力一致性校验。当前任务声明偏好与真实模型扰动实验得到的敏感性严格分开。

## 4. 遗传变异及最优性的范围

复用官方 GOLEM `EvoGraphOptimizer`，多目标保守效用向量，记录父子图、有效/无效变异、随机补充和 Pareto 集。不是把排序过程改名为遗传算法。参数示例：

```json
{
  "portrait_policy": {"version": "已发布版本", "scenario": "已发布场景", "memory_version": "可选开发响应版本"},
  "profile_options": {"search": {"strategy": "genetic", "population": 6, "generations": 4, "proposal_limit": 100, "exact_check": true}}
}
```

原硬过滤及冻结类型图域保留，当前候选上限128；截断域不冒充完整域。候选画像评分先构建，遗传过程不声称节约这部分成本。`exact_check=true` 可核查整个冻结域，证书仅为 **EXHAUSTIVE_SCORE_LOWER_BOUND_IN_FROZEN_DOMAIN**。遗传算法本身不保证全局最优，证书也不证明真实数值效果全局最优。最终所选图仍走实际数值管线。

## 5. 验收与证据

- 最新相关回归：`output/joint_state_20261024/regression_release.xml`；此前较广回归135项通过，记录在 `regression_final.xml`。最终小修涉及效用区间的一致性，另重跑52项相关检查通过。存在依赖弃用警告，未隐瞒。
- 最新端到端证据：`output/joint_state_20261024/acceptance_v3`。6次合成场景调用真实数值内核，加1次真实多源入口调用，共35份数值产品；真实多源11张图全部执行。
- 独立审计：`output/joint_state_20261024/independent_audit.json`。重算风险、加权区间、推荐顺序，核对产品SHA与实际缺失状态，7份决策、35份产品通过；轨迹含11次改变图的有效原生变异。
- 已证明数据变化、模型场景变化可改变对应推荐；未知副作用不伪填；参考真值不参与推荐；分组隔离与更名去重生效；页面和文件入口共用决策。
- 响应库含8条整链记录与8条算法响应记录，仅作功能验证，不代表样本充足。

真实数据保留原有坐标工作假设和协变量限制；GEOS不是地面真值。本轮没有运行 WRF/CMAQ 等原生模拟，也没有重跑正式优越性实验。旧实验中校准评分未胜最强固定方案的结论不变。下一阶段须在冻结策略、独立任务和统一成本下检验科学收益，不能以本轮机制通过替代效果证据。
