# 共同强基准与变异预算：冻结协议

复用现有公共 Composition、三路可见锚点探测、ALNS与SearchValidation；本轮不新增数值算法或替代排序器。

共同强基准包含两条开发冻结路线：此前8个开发案例、1296张图中的最强固定组合；以及相同开发数据上真实执行、从细源线性与粗源双线性/PCHIP三个单算法参照中选出的最强单源方案。参照文件带SHA256、开发组和任务范围，不接收验证/测试选出的基准。

同一请求用同一批可见锚点遮挡实测两个参照，以跨两个探测窗口的整体RMSE选择较强参照；这个参照对全部1296候选相同。协同收益为共同参照RMSE减候选RMSE；有界展示为(1+(e_ref-e)/(e_ref+e))/2，零除定义为零收益。不会再以候选自身分支作为加分起点。

主评分复用开发支持的数据/模型各0.5；协同收益不再相加，只在主评分相同时用于比较，并输出是否两个探测窗口都正改善的收益判断。该判断是有限可见证据，不是置信区间或未知测试效果保证。硬约束与最终质量门保留。提供搜索验证标签时，最终主目标仍为真实验证RMSE。

公共配置使用composition.parallel_scoring.common_reference声明path和sha256；该模式collaboration加权系数必须为0，避免偷偷重复加权。完整三路诊断与共同收益仍输出；旧加权机制保留作对照。

采用4组新时空配对：两个未参与权重校准的东部区域，各取新验证起始2000、2700及后续测试2070、2770；每例33时次。上一轮测试不作为本轮新测试。仍为同源NCEP受控互补分辨率数据，不宣称独立传感器或WRF响应。

4方法×5种子（11、29、47、71、101）：共同基准评分＋ALNS、原协同加权＋ALNS、随机初始化且不使用三路软评分的ALNS、纯随机。统一最多256次唯一真实执行、4096提议、1800秒，ALNS内部通用提议容量6400大于显式提议上限。实际提前停止保留，不补换种子。

从同一条有界轨迹取32、128、256次执行的嵌套前缀，比较预算增长；前缀不是独立重复。每次完整图真实执行、保存和回读产品，不读预计算误差表。72次局部探测及4次参照探测成本另列；纯随机/无评分对照不支付该探测成本。

所有前缀选图先冻结，再独立运行每例1296张图的穷举参照；正式搜索exact_check=False，禁止穷举补齐或最优知情停止。命中前两次属于初筛；其后首次命中才计作变异阶段命中。穷举结果只用于事后确认验证最优，不能计入变异命中率。

穷举执行的资源安排：选择冻结后复用同一案例已真实执行、匹配计划且文件哈希与误差均重算通过的产品，只执行尚未覆盖的图；账本逐条标明REUSED_REAL_EXECUTION或ORACLE_COMPLETION_ONLY。这个安排不修改任何搜索规则和预算，独立覆盖1296图；不得把补齐产品回写搜索结果或冒称变异额外命中。

所有选择冻结后才评价后续测试。报告验证最优命中、初筛与变异拆分、失败及实际预算、测试RMSE、开发固定方案和随机对照。20次种子运行只对应4组时空案例，不证明无条件全局收敛。若共同评分初始已命中，明确认定无需变异，不能冒称变异优势。
