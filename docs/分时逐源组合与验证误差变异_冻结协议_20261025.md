# 分时逐源组合与真实验证误差反馈：冻结协议

## 问题与范围

检验：三画像过滤和初始排序后，依据真实验证误差反馈的自适应破坏—修复，能否比普通变异和纯随机搜索更少执行就达到有限候选域的验证全局最优。不能保证达到独立测试误差最优，不能把遍历保证归功于变异。

仅复用现有平台公共服务，新增独立SearchValidation端口和必要的SciPy三乘三空间中位数过滤适配器。滤波可能抹去真实细节；不预先规定它有收益。没有训练新模型、不将评分画像替换成黑箱排序、不读取最终测试来决定变异。

## 全部合法组合先计数

每时段：

1. 细空间源：已有线性时间插值，1种。
2. 粗空间源：双线性/PCHIP两种空间方法；中位数过滤可跳过、位于空间处理之前或之后，因此6种不同链。
3. 融合：细源主导0.75、粗源主导0.75、已有半强度细节投影，3种。系数是冻结候选值，不冒充不确定性。
4. 融合后：中位数过滤关/开，2种。

两个独立时段：`(1×6×3×2)²=1296`种。上下时段所有分支相同时为36种。排序中的可选空节点和相同拓扑链已去重；可能数值相等的不同结构不冒充不同科学方法。初始化前全部经过现有结构检查及三画像评分，不随机截取。计数工具已在12个数据组各核实1296种结构兼容、0种结构拒绝；数值执行通过数与不同数值产物数另行统计。

这是任务代表性有限语法，包含真实的先后、主辅、分时和逐源差异，不是算法库所有可能DAG。没有为了称“全局”而把无限参数和任意长度流程混进分母。范围在正式执行前冻结。

## 数据和隔离

真实文件data/ncep_xarray/air_temperature.nc，取既有12×12区域，每组17个6小时时刻。源A为第0、8、16时刻的12×12场（48小时）；源B为全部17个时刻经既有面积观测算子得到的6×6场（6小时）。恢复另外14个细场，前后两段各7个目标时刻。历史重建可利用两侧已提供锚点。

源数据为同一真实再分析的受控降采样，非独立传感器；2.5°原生格点只称相对细/粗。面积支持为本实验显式离散假设，不声称原生传感器代表性。中位数不是人为注入噪声的反向修复；直接检验自然场是否值得过滤。

- 开发：2013年起始索引80、440、800、1160，各17时刻，用于确定最强固定图及固定分时相同方案。
- 搜索验证/独立测试成对：1510/1540、1870/1900、2230/2260、2590/2620；每组各17时刻，不重叠。验证组隐藏细场标split=search_validation；最终测试标split=test。
- 搜索阶段仅加载对应验证组标签；所有案例全部选图冻结并保存后，才加载最终测试标签计算结果。最终测试数据不传给搜索或排序模块。
- 平台只允许显式SearchValidation作为反馈，检查变量、单位、目标时间、可见细锚点及独立评价时间重叠。不能把测试标签资源当作搜索验证传入。

## 决策和目标

先三画像完整初筛：物理输入约束保留，模型场景为已发布的粗观测一致与锚点细节偏离，未知保留区间，不新增任意模型敏感度。新滤波画像未知项不填写数值。模型仅代表WRF温度输入契约及声明的工程偏好，未运行WRF。

初筛前2图实际执行，随后由验证RMSE决定接受与优劣；画像分仅在RMSE差不超过1e-9K时参与并列排序，后续再按步骤数与索引决定。每个新候选图真实执行并通过质量门后才计算固定验证队列误差，失败保留并判不可用。缓存只复用同请求、同输入及同链真实产物；重复提议不算新增数值执行。

ALNS7/AlphaUCB的源、融合/后处理、时窗、全局轴破坏与随机/画像引导修复继续复用，算子奖励改为真实验证误差改善；普通变异保持相同合法域、初筛种子和预算。三画像负责适用性与初始引导，变异反馈明确使用可监督验证误差，不再把画像分最高当成误差最低。

## 对照、公平性与停止

每个验证案例种子11、29、47、71、101：ALNS、普通变异、纯随机、仅三画像初始方案。前两者及仅初筛共享相同初始2图。纯随机仍经过全量合法域建立，但忽略排序均匀选初始图、均匀无放回扩展；这是实验对照，生产顺序不变。后端每次预算64次唯一真实评价、256次提议、900秒；仅初筛实际执行2图，成本如实保留。

先运行搜索，再用独立全量真实执行获取1296图验证误差最优。穷举器不把表返回给搜索。四个开发组穷举选出平均验证误差最小的固定整图，以及36种上下时段相同图中的最强固定；两个基线均在测试前冻结。最终测试只执行已冻结的图与固定方案，不按测试成绩重选。

主指标：达到穷举验证最优（1e-9K容差）的成功率、首次达到所需唯一执行次数/墙钟、失败按实际耗尽预算计的成功期望成本；同时报告合法率、实际内核/缓存成本、独立测试RMSE/MAE/Bias。单看命中者速度可能偏差，必须同时报告失败和成功率。四案例为分析组，五种子只是搜索重复，不作为20个独立数据集。无足够证据时不做显著优势宣称。

不根据测试或失败种子反复更改候选池、阈值、种子或预算。全量执行可认证有限域验证目标最优，未覆盖域或独立测试泛化不保证全局最优。搜索未胜随机、未胜固定、评分误导及失败图都保留。

## 验收

定向测试：先后链与1296计数、原生验证反馈、真实误差最小图选择、错误标签用途及重叠拒绝；相关旧接口回归。独立审计回读保存产品和标签，重算全部RMSE、推荐、穷举最优和首次命中，不只看报告。文件/页面处理函数同入口验收，测试标签扰动不能改变已冻结推荐。代码、原始数据、配置和画像指纹保存于output/scheduled_fusion_20261025。
